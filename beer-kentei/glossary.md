## 分類ツリー

> MECEに整理できる概念。同レベルの項目は互いに重複せず、列挙が原則として完全。

### ビアスタイル

**カテゴリ**: ビアスタイル  
**概要**: 発酵方式を軸にしたビールスタイルの分類体系

**MECEである理由**

ビールは「酵母が発酵する場所（温度帯）」によって上面発酵・下面発酵・自然発酵の3種に完全分類できる。この3区分は互いに重複せず、既存のすべてのビールスタイルを収容できるため、最上位の分類軸としてMECEが成立する。各区分内のスタイル（IPA・ピルスナー等）も原則として排他的であり、同一ビールが複数スタイルに同時に属することはない。

```
ビール
├── エール（上面発酵 / Ale yeast / 高温発酵 15〜25°C）
│   ├── ペールエール：淡色・ホップ香、英国発祥
│   ├── IPA（India Pale Ale）：高ホップ苦味・香り（輸送防腐目的が起源）
│   ├── スタウト：黒色・ロースト香・濃厚（アイルランド発祥、ギネス代表）
│   ├── ポーター：スタウトより軽め・チョコレート香（英国発祥）
│   ├── ヴァイツェン：小麦麦芽50%以上・バナナ香（南ドイツ）
│   ├── アルト：「古い」製法の上面発酵・銅色（デュッセルドルフ）
│   ├── ケルシュ：淡色上面発酵・下面発酵的クリアさ（ケルン限定）
│   └── イングリッシュブラウンエール：ナッツ香・琥珀色（英国）
├── ラガー（下面発酵 / Lager yeast / 低温発酵 5〜15°C）
│   ├── ピルスナー：淡色・軽快・ホップ香（チェコ発祥）
│   ├── ヘレス：淡色・ピルスナーより麦芽感強（バイエルン）
│   ├── メルツェン：琥珀色・麦芽甘味（オクトーバーフェスト）
│   ├── ボック：高アルコール・濃厚・麦芽主体（アインベック起源）
│   ├── シュバルツ：黒ビール・ロースト麦芽・下面発酵（テューリンゲン等）
│   └── ラオホ：燻製麦芽使用・スモーキー（バンベルク名物）
└── 自然発酵（野生酵母・バクテリア）
    ├── ランビック：野生酵母発酵・ベルギー
    ├── グーズ：ランビックをブレンドして二次発酵
    └── フルーツランビック：クリーク（さくらんぼ）等
```

**収録項目**: ピルスナー / ヘレス / メルツェン / ボック / シュバルツ / ラオホ / IPA / スタウト / ポーター / ヴァイツェン / アルト / ケルシュ / ランビック / グーズ

**関連問題**: Q001, Q002, Q006, Q009, Q013, Q018, Q019, Q025

**試験対策ポイント**

- **最頻出**: ピルスナー=下面発酵、ヴァイツェン=上面発酵・小麦使用の組み合わせ
- **混同注意**: スタウトとポーターは両方上面発酵・黒色系だが、スタウトの方が濃厚
- **ランビックは「自然発酵」**: 酵母を添加しない点が他スタイルと本質的に異なる
- **IPA**: 「India」は輸送先であり、インド産ホップを使うわけではない

### ビール醸造工程

**カテゴリ**: 醸造工程  
**概要**: 製麦から充填までのビール製造全ステップの順序分類

**MECEである理由**

ビールの製造工程は「製麦→仕込み→発酵→熟成→ろ過→パッケージング」の時系列ステップに完全に分解できる。各工程は前後の工程と明確に区別された目的・処理内容を持ち、重複しない。すべてのビールはこの工程を経て製造されるため、網羅性も成立する。

```
ビール醸造工程
├── 1. 製麦（Malting / モルティング）
│   ├── 浸麦（Steeping）：大麦を水に浸して吸水・発芽を促す
│   ├── 発芽（Germination）：約1週間かけて酵素を生成させる
│   └── 焙燥（Kilning）：熱風・直火で乾燥。色と風味が決まる
├── 2. 仕込み（Brewing）
│   ├── 粉砕（Milling）：麦芽を砕いてデンプンを露出させる
│   ├── 糖化（Mashing）：温水と混合（マイシェ）→酵素でデンプンを糖に変換
│   ├── ろ麦汁（Lautering）：麦汁を穀皮から分離
│   └── 煮沸（Boiling）：ホップ添加・殺菌・タンパク凝固（ブルッフ除去）
├── 3. 主発酵（Primary Fermentation）
│   ├── 酵母添加（Pitching）：冷却した麦汁に酵母を投入
│   ├── アルコール生成：酵母が糖をエタノール+CO₂に変換
│   └── 若ビール（Green Beer）生成：発酵直後の未熟な状態
├── 4. 後発酵・熟成（Secondary Fermentation / Lagering）
│   ├── 低温貯蔵（0〜4℃）：オフフレーバーの除去・炭酸飽和
│   ├── ジアセチル除去：酵母が再吸収して分解
│   └── 清澄化：タンパク・酵母が沈降して透明度向上
├── 5. ろ過（Filtration）
│   └── 酵母・タンパク・濁り成分の除去
└── 6. パッケージング（Packaging / 充填）
    ├── CO₂パージ：容器内の酸素を炭酸ガスで置換
    ├── 充填（Filling）：等圧充填でびん・缶・樽に充填
    └── 殺菌（Pasteurization）：熱処理または無菌ろ過
```

**収録項目**: 製麦（モルティング） / 仕込み（マッシング・煮沸） / 主発酵 / 後発酵・熟成（ラガリング） / ろ過 / パッケージング（充填） / マイシェ / 麦汁（ワート） / ブルッフ

**関連問題**: Q002, Q008, Q014, Q015, Q018, Q021, Q023, Q026

**試験対策ポイント**

- **工程の順番**：製麦→仕込み（糖化→煮沸）→主発酵→熟成→ろ過→充填 の順序ごと覚える
- **マイシェ＝糖化中の麦芽＋温水の混合物**（マッシュ）
- **若ビール（グリーンビール）＝主発酵直後の未熟なビール**
- **ブルッフ＝煮沸で生じるタンパク凝固物**（除去することでビールが清澄になる）
- **ラガリング＝低温貯蔵・熟成**（ジアセチル除去・炭酸飽和・清澄化が目的）
- **CO₂パージ＝充填前の酸素除去**（酸化防止と発泡抑制の2つの目的）

### 発酵方式

**カテゴリ**: 醸造工程  
**概要**: 酵母の働く温度帯・場所によるビール発酵の三分類

**MECEである理由**

ビールの発酵は「酵母の種類と発酵温度帯」によって上面・下面・自然の3方式に完全に分類できる。この3区分は互いに排他的（同一ビールが複数方式に同時に属することはない）であり、現存するすべての醸造ビールを網羅する。自然発酵は人工酵母を添加しないという製法上の差異で明確に区別できるため、MECE成立。

```
発酵方式
├── 上面発酵（Ale fermentation）
│   ├── 酵母：Saccharomyces cerevisiae（エール酵母）
│   ├── 発酵温度：15〜25℃
│   ├── 発酵期間：3〜5日（下面より短い）
│   ├── 酵母の挙動：発酵後、液面上部に浮上・凝集
│   └── 代表スタイル：ペールエール・IPA・スタウト・ヴァイツェン・アルト・ケルシュ
├── 下面発酵（Lager fermentation）
│   ├── 酵母：Saccharomyces pastorianus（ラガー酵母）
│   ├── 発酵温度：5〜15℃
│   ├── 発酵期間：1〜2週間（上面より長い）
│   ├── 酵母の挙動：発酵後、容器底部に沈降
│   └── 代表スタイル：ピルスナー・ヘレス・メルツェン・ボック・シュバルツ
└── 自然発酵（Spontaneous fermentation）
    ├── 酵母：野生酵母・乳酸菌・酢酸菌など複数の微生物
    ├── 発酵温度：屋外・季節依存（冬季が中心）
    ├── 発酵期間：数ヶ月〜数年
    ├── 酵母の挙動：空気中の野生微生物が自然に定着
    └── 代表スタイル：ランビック・グーズ・クリーク（フルーツランビック）
```

**収録項目**: 上面発酵 / 下面発酵 / 自然発酵 / エール酵母 / ラガー酵母 / 野生酵母

**関連問題**: Q002, Q013, Q015, Q019

**試験対策ポイント**

- **上面=エール（高温・短期・フルーティ）、下面=ラガー（低温・長期・クリーン）** のセットで覚える
- **発酵期間の数字**: 上面3〜5日・下面1〜2週間は数値ごと出題される
- **アルトとケルシュは上面発酵**: 色が濃い/場所がドイツというイメージから下面と混同しやすい
- **ヴァイツェンは上面発酵**: 小麦ビールだが上面発酵酵母使用
- **ランビックは「自然発酵」**: 「酵母を添加しない」という点が最大の特徴

### ホップの品種分類

**カテゴリ**: 原材料  
**概要**: 使用目的・成分特性によるホップ品種の分類体系

**MECEである理由**

ホップ品種は「α酸含有量（苦味成分）と精油成分（香り成分）の比率」によってビターホップ・アロマホップに大別される。この2軸は主たる使用目的の違いであり、実用上重複しない分類として機能する。ノーブルホップはアロマホップの上位概念として「伝統的な欧州産・低α酸・繊細な香り」という条件で厳密に定義されるため、サブカテゴリとしてMECEが成立する。

```
ホップ品種
├── ビターホップ（Bittering Hop）
│   ├── α酸含有量：高（10〜15%以上）
│   ├── 香り精油：少ない
│   ├── 主な役割：苦味付け（煮沸前半に添加）
│   └── 代表品種：マグナム、ナゲット、チヌーク
└── アロマホップ（Aroma Hop）
    ├── α酸含有量：低（2〜7%程度）
    ├── 香り精油：豊富
    ├── 主な役割：香り付け（煮沸後半〜フレッシュホップ添加）
    ├── ファインアロマホップ（Fine Aroma Hop）
    │   ├── 定義：アロマホップの中でも特に香り品質が高く繊細なもの
    │   ├── ノーブルホップ（Noble Hop）
    │   │   ├── 欧州伝統4品種：ザーツ / ハラタウ / テトナング / シュパルター
    │   │   ├── 特徴：α酸2〜5%、スパイシー・ハーバル・フローラルな上品な香り
    │   │   └── 産地：ボヘミア（チェコ）・ドイツ（バイエルン〜フランケン）
    │   └── その他ファインアロマ：イーストケント・ゴールディングス（英）等
    └── アメリカン・アロマホップ
        ├── 代表品種：カスケード、センテニアル、シムコー
        └── 特徴：シトラス・トロピカル・松ヤニ様の強い香り
```

**収録項目**: ビターホップ / アロマホップ / ファインアロマホップ / ノーブルホップ / ザーツ / ハラタウ / テトナング / マグナム / カスケード

**関連問題**: Q004, Q014, Q016, Q019, Q020

**試験対策ポイント**

- **ノーブルホップ4品種をすべて覚える**: ザーツ・ハラタウ・テトナング・シュパルター
- **ザーツ＝チェコ（ボヘミア）**: ピルスナーの香りの源。チェコのザーツ（現サアス）市周辺が産地
- **ハラタウ＝世界最大の産地**: バイエルン北部。ドイツ産ホップの代名詞
- **ビター（高α酸）とアロマ（低α酸・高精油）の使い分け**を理解する
- **ファインアロマホップ**: 検定では「アロマホップの中でも特に香り品質が高い品種」として出題

## 用語定義

> MECEツリーに収まらない独立した概念の定義。プロセス・測定値・技法・固有名詞など。

### 原材料

#### ルプリン / *Lupulin* / （るぷりん）

> ホップの毬花内部の黄色粉末。苦味・香りの源

**ルプリン**（るぷりん）: ホップの毬花（球花）の花弁の基部に存在する黄色〜黄金色の粉末状の腺。ホップの苦味成分（α酸・β酸）と香り成分（精油）が凝縮されており、ビール醸造においてホップが果たす役割の本体となる部位。

### ルプリンの成分

ルプリン腺には以下の成分が含まれる。

| 成分 | 役割 | ビールへの影響 |
|------|------|-------------|
| **α酸（フムロン類）** | 苦味の前駆体 | 煮沸によってイソアルファ酸（苦味）に変換。IBUの基準値 |
| **β酸（ルプロン類）** | 抗菌作用・若干の苦味 | 煮沸ではほぼ変換されないが、酸化で苦味を生じることも |
| **精油（エッセンシャルオイル）** | 香りの源 | ミルセン・フムレン・ゲラニオール等。揮発しやすく香り付けに使用 |
| **ポリフェノール（タンニン）** | 清澄作用 | タンパク質と結合して沈殿し、麦汁を清澄にする |

### ホップの植物的特徴

ホップ（*Humulus lupulus*）はアサ科カラハナソウ属のつる性の多年草。雌雄異株で、醸造に使用されるのは**未授精の雌株の毬花（球花）**のみ。雄株が近くにあると種子が形成されてルプリンの品質が低下するため、栽培地では雄株を除去する。

ルプリンは毬花を縦に割ると内側に見える、鮮やかな黄金色の粒状粉末。フレッシュなホップほどルプリンが豊富で、鮮度管理が重要。

### 使用形態

ホップは通常以下の形態で使用される。

| 形態 | 特徴 |
|------|------|
| 生ホップ（フレッシュホップ） | 収穫直後。香りが最も豊か。フレッシュホップビールに使用 |
| ペレットホップ | 乾燥・粉砕・圧縮成型。最も一般的。保存性に優れる |
| ホップエキス | ルプリン成分を溶剤で抽出。標準化しやすい |

**関連用語**: ホップ / 毬花 / アルファ酸 / 精油 / IBU

**関連問題**: Q020

#### 二条大麦 / *Two-row barley* / （にじょうおおむぎ）

> ビール醸造の標準原料となる大麦品種

**二条大麦**（にじょうおおむぎ）: 穂の左右2列にのみ実がつく大麦品種。ビール醸造用の主要穀物として世界中で最も広く使われる。

大麦は穂軸の節に実がつく列数によって「条性」で分類される。二条大麦は各節に1粒だけ（左右で計2列）着粒するため、粒が大きく形が揃いやすい。

**醸造に適した理由:**
- **デンプン含有量が高い**: 糖化効率が良く、発酵可能な糖を多く得られる
- **タンパク質が少ない**: 麦汁の透明度が上がり、清澄なビールになる
- **粒が均一**: 製麦（モルティング）の管理がしやすい

**主な産地**: ドイツ・チェコ・イギリス・オーストラリア・カナダ・日本（「サチホゴールデン」「ニシノホシ」等）

**六条大麦との比較:**

| 項目 | 二条大麦 | 六条大麦 |
|------|----------|----------|
| 着粒列数 | 2列 | 6列 |
| 粒の大きさ | 大・均一 | 小・不均一 |
| デンプン量 | 多い | 少ない |
| タンパク質量 | 少ない | 多い |
| 主な用途 | **ビール醸造** | 食用・飼料・一部ビール |

**関連用語**: 六条大麦 / 麦芽 / デンプン / 糖化

**関連問題**: Q001

### 醸造工程

#### IBU・ABV・SRM・EBC / *IBU / ABV / SRM / EBC* / （アイビーユー・エービーブイ・エスアールエム・イービーシー）

> ビールの苦味・アルコール・色を表す数値指標

ビールの特性を数値で表す4つの主要指標。

- **IBU**（International Bitterness Units / 国際苦味単位）：ビールの苦味の強さを表す指標
- **ABV**（Alcohol By Volume / アルコール度数）：容量に対するアルコールの割合（%）
- **SRM**（Standard Reference Method）：アメリカ式のビールの色の指標
- **EBC**（European Brewery Convention）：ヨーロッパ式のビールの色の指標

### IBU（苦味単位）

IBUはホップ由来の苦味成分（イソアルファ酸＝イソフムロン）の濃度をmg/Lで表した数値。1 IBU = イソアルファ酸 1mg/L に相当する。

| IBU値 | 苦味感 | 代表的なスタイル |
|-------|--------|----------------|
| 5〜15 | ほとんど苦くない | 軽いラガー・ヴァイツェン |
| 15〜30 | 軽い苦味 | ピルスナー・ペールエール |
| 30〜60 | 中程度の苦味 | IPA・ペールエール |
| 60〜100+ | 強い苦味 | ダブルIPA・インペリアルIPA |

ただし、麦芽の甘みがIBUの苦味を中和するため、実際の苦味感はIBUだけでは判断できない（甘いビールは高IBUでも苦く感じにくい）。

### ABV（アルコール度数）

容量パーセントで表すアルコール量。日本の一般的なビールは約4.5〜5.5%。

| ABV | 分類 | 例 |
|-----|------|---|
| 〜3.5% | ローアルコール | ノンアルコール・ライトビール |
| 4〜6% | 標準 | 一般的なラガー・ピルスナー |
| 6〜9% | 強め | IPA・ボック |
| 9%以上 | ストロング | インペリアルスタウト・バーレーワイン |

### SRM と EBC（色指標）

どちらもビールの色を数値化したもの。SRMはアメリカ基準、EBCはヨーロッパ基準で、数値が大きいほど色が濃い（黒い）。

| 色 | SRM | EBC | 代表スタイル |
|----|-----|-----|------------|
| 薄黄〜黄金色 | 2〜5 | 4〜10 | ピルスナー・ヘレス |
| 琥珀色 | 6〜15 | 12〜30 | アンバーエール・メルツェン |

#### オフフレーバー / *Off-Flavor* / （おふふれーばー）

> ビールの正常な風味を損なう望ましくない香味成分

**オフフレーバー**（おふふれーばー）: 醸造・保存工程の不具合や品質劣化によってビールに生じる、スタイル本来の香味から外れた望ましくない香り・味のこと。品質管理において最も重視される評価項目の一つ。

### 主要なオフフレーバーとその原因

| オフフレーバー | 香り・味 | 主な原因 | 閾値の目安 |
|--------------|---------|---------|-----------|
| **ジアセチル** | バター臭・乳製品臭 | 熟成不足（酵母による再吸収が不十分） | 約0.1 mg/L（非常に低い） |
| **アセトアルデヒド** | 青リンゴ臭・青草臭 | 発酵不足（中間産物が残存） | 約10 mg/L |
| **DMS（ジメチルスルフィド）** | 缶詰コーン臭・野菜臭 | 煮沸不足・麦汁の冷却遅延 | 約30 µg/L |
| **光臭（スカンキー）** | 日光臭・スカンク臭 | UV・可視光線によるイソアルファ酸の分解 | 極微量でも感知 |
| **酸化臭** | 紙臭・段ボール臭・老化臭 | 酸素との接触（トランス-2-ノネナール生成） | 約0.1 µg/L |

### 各オフフレーバーの詳細

#### ジアセチル（Diacetyl）
発酵中に酵母がα-アセト乳酸を分泌し、酸化されてジアセチルに変換される。正常な発酵では、熟成段階で酵母がジアセチルを再吸収・分解する。閾値（0.1 mg/L前後）が非常に低く、微量でも感知される。**熟成不足が主因**。一部スタイル（チェコのボヘミアンピルスナーなど）では微量の存在が許容される。

#### アセトアルデヒド（Acetaldehyde）
アルコール発酵の中間産物。正常な発酵では酵母がエタノールに変換して除去するが、**発酵が不完全**だと残存する。若ビール（発酵直後）に多く、熟成とともに減少する。

#### DMS（Dimethyl Sulfide）
麦汁中の前駆体（SMM：S-メチルメチオニン）が熱分解して生成。**煮沸が不十分**だと除去されずに残る。また、麦汁の冷却に時間がかかるとSMMがDMSに変換される量が増える。

#### 覚え方（試験対策）
- **バター臭 → ジアセチル**（熟成不足）
- **青リンゴ臭 → アセトアルデヒド**（発酵不足）
- **コーン臭 → DMS**（煮沸不足）

**関連用語**: ジアセチル / アセトアルデヒド / DMS / 熟成 / 発酵

**関連問題**: Q007

#### ブルッフ / *Bruch / Hot Break / Cold Break* / （ぶるっふ）

> 麦汁煮沸・冷却で生じるタンパク凝固物

**ブルッフ**（ぶるっふ、独: Bruch〔破砕・凝固〕）: 麦汁の煮沸工程および冷却工程においてタンパク質とポリフェノール（タンニン）が結合・凝固して生じる沈澱物。ビールの清澄化と品質安定のために除去される。英語では煮沸後の凝固物を**ホットブレイク（Hot Break）**、冷却後の凝固物を**コールドブレイク（Cold Break）**と呼ぶ。

### ブルッフの生成メカニズム

麦汁（仕込み後の液体）には多量のタンパク質とポリフェノールが溶解している。これらは加熱によって変性・反応し凝固物（ブルッフ）を形成する。

#### ホットブレイク（煮沸中）
煮沸（95〜100℃）によってタンパク質が熱変性し、ホップ由来のポリフェノール（タンニン）と結合して大きな凝集塊を形成する。煮沸終了後にワールプール（旋回槽）に移し、遠心力で凝集物を中央に集めて分離する。

#### コールドブレイク（冷却中）
煮沸後の麦汁を急速冷却（10〜20℃）する際、熱で解けていたタンパク質とポリフェノールの複合体が再び凝集して沈殿する。プレートクーラーや沈降槽で除去される。

### 除去する理由

| 残存するとどうなるか | 除去すると |
|-------------------|---------|
| 濁り（haze）が生じる | 澄んだ外観になる |
| タンパク質が発酵を阻害 | 酵母の活性が上がる |
| 口当たりがざらつく | なめらかな飲み口になる |
| 品質劣化が早まる | 保存性が向上する |

### 関連工程：ホイールプール（Whirlpool）

煮沸終了後に麦汁を旋回させ、遠心力によってブルッフ（ホップの残渣も含む）を槽中央に堆積させて除去する工程。日本語では「旋回槽」とも呼ぶ。

**関連用語**: 麦汁煮沸 / タンパク質 / 清澄化 / ホップ / ポリフェノール

**関連問題**: Q018

#### マイシェ / *Mash / Maische* / （まいしぇ）

> 糖化工程で麦芽と温水を混合したおかゆ状の混合物

**マイシェ**（まいしぇ、独: Maische）: 仕込み工程において、粉砕した麦芽と温水を混合した**おかゆ状の混合物**。英語では「マッシュ（Mash）」と呼ぶ。マイシェを加熱・保温することで麦芽中の酵素（アミラーゼ・プロテアーゼなど）が活性化し、デンプンや高分子タンパク質が分解されて発酵可能な糖・アミノ酸を含む麦汁が生成される。

### マイシェ（糖化）の工程

マイシェを特定の温度に段階的に保持する（**マッシング**または**段階醸造法**）ことで、各温度帯に最適な酵素を順番に働かせる。

| 工程名 | 温度 | 主な酵素 | 目的 |
|--------|------|---------|------|
| **タンパク休止（プロテイン・レスト）** | 45〜55℃ | プロテアーゼ | タンパク質を分解→泡持ち改善・ろ過性向上 |
| **糖化（サッカリフィケーション）** | 62〜65℃ | β-アミラーゼ | デンプンを発酵性糖（マルトース）に分解 |
| **糖化（デキストリン化）** | 68〜72℃ | α-アミラーゼ | デンプンをデキストリン（非発酵性）に分解→ボディ感 |
| **マッシュアウト** | 76〜78℃ | 全酵素の失活 | 酵素反応を止めてろ麦汁工程へ移行 |

### 「おかゆ状」という表現

「マイシェはおかゆ状」という記述はビール検定の公式テキストにも登場する定義で、試験で問われることがある。

### マイシェとマッシングの違い

- **マイシェ（Maische）**: 麦芽＋温水の混合物そのもの（名詞）
- **マッシング（Mashing）**: マイシェを作って糖化させる操作・工程（動詞・プロセス）

### 糖化後の処理

糖化が完了したマイシェを**ロイタータン（濾過槽）**に移し、穀皮をフィルターとして麦汁（ワート）を分離する（**ロイタリング**）。得られた麦汁はその後煮沸工程に進む。

**関連用語**: 糖化 / マッシング / アミラーゼ / プロテアーゼ / タンパク休止 / 麦汁

**関連問題**: Q014, Q023

### 法規制

#### ビール純粋令 / *Reinheitsgebot* / （びーるじゅんすいれい）

> 1516年制定のドイツのビール原料規制法令

**ビール純粋令**（びーるじゅんすいれい、独: Reinheitsgebot〔ラインハイツゲボート〕）: 1516年にバイエルン公国のヴィルヘルム4世が制定したビールの原料に関する法令。「ビールは大麦・ホップ・水のみを使用しなければならない」と規定した世界最古の食品規制法の一つ。

### 制定の背景と内容

1516年4月23日、バイエルン公ヴィルヘルム4世とルートヴィヒ10世が連名で公布。制定当時に規定された原料は**大麦・ホップ・水の3つ**。酵母は当時その存在が知られていなかったため条文には含まれていないが、現代では「4つの原料（大麦・ホップ・水・酵母）」として認識されることが多い。

| 制定時の規定 | 現代の解釈 |
|------------|---------|
| 大麦（Gerste） | 麦芽（モルト）。小麦などは原則使用不可 |
| ホップ（Hopfen） | 苦味・香り付け原料 |
| 水（Wasser） | 醸造用水 |
| ―（未記載） | 酵母（Hefe）：発酵に不可欠だが当時未知 |

### 歴史的意義

- **世界最古の食品規制法**の一つとして歴史的に重要
- 品質保証：当時はグルートと呼ばれるハーブ混合物など、毒性のある材料が使われることもあり、それを防ぐ目的があった
- 穀物の確保：小麦・ライ麦はパン用として確保し、ビールには大麦のみ使用させる穀物管理の側面もあった
- 現代ドイツのビール文化のアイデンティティとして、法的効力はないものの今日まで語り継がれている

### 現代のドイツでの扱い

ドイツ統一後の1987年に純粋令に基づく法律は改正・廃止されたが、「ドイツ式ビールの伝統」として多くのドイツのブルワリーが今も純粋令に準拠したビールを醸造し、そのことを誇りにしている。

**関連用語**: 大麦 / ホップ / 水 / 酵母 / バイエルン

**関連問題**: Q020
