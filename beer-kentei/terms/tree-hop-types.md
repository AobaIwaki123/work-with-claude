# ホップの品種分類ツリー

## なぜMECEか

ホップ品種は「α酸含有量（苦味成分）と精油成分（香り成分）の比率」によってビターホップ・アロマホップに大別される。この2軸は主たる使用目的の違いであり、実用上重複しない分類として機能する。ノーブルホップはアロマホップの上位概念として「伝統的な欧州産・低α酸・繊細な香り」という条件で厳密に定義されるため、サブカテゴリとしてMECEが成立する。

## 分類ツリー

```
ホップ品種
├── ビターホップ（Bittering Hop）
│   ├── α酸含有量：高（10〜15%以上）
│   ├── 香り精油：少ない
│   ├── 主な役割：苦味付け（煮沸前半に添加）
│   └── 代表品種：マグナム、ナゲット、チヌーク
└── アロマホップ（Aroma Hop）
    ├── α酸含有量：低（2〜7%程度）
    ├── 香り精油：豊富
    ├── 主な役割：香り付け（煮沸後半〜フレッシュホップ添加）
    ├── ファインアロマホップ（Fine Aroma Hop）
    │   ├── 定義：アロマホップの中でも特に香り品質が高く繊細なもの
    │   ├── ノーブルホップ（Noble Hop）
    │   │   ├── 欧州伝統4品種：ザーツ / ハラタウ / テトナング / シュパルター
    │   │   ├── 特徴：α酸2〜5%、スパイシー・ハーバル・フローラルな上品な香り
    │   │   └── 産地：ボヘミア（チェコ）・ドイツ（バイエルン〜フランケン）
    │   └── その他ファインアロマ：イーストケント・ゴールディングス（英）等
    └── アメリカン・アロマホップ
        ├── 代表品種：カスケード、センテニアル、シムコー
        └── 特徴：シトラス・トロピカル・松ヤニ様の強い香り
```

## 各項目の解説

### ビターホップ

α酸（フムロン）含有量が高く（10〜15%以上）、煮沸によってイソアルファ酸（イソフムロン）に変換され苦味を付与する。精油成分（香り）は少ないため、通常は煮沸工程の早い段階（60〜90分前）に添加する。高α酸品種は少量で十分な苦味が得られるため、経済的にも有利。

### アロマホップ

α酸含有量が低く（2〜7%程度）、豊富な精油成分による繊細な香りが特徴。煮沸終了直前（ファイナルホッピング）や、発酵・熟成後に添加するドライホッピングに使用する。熱で揮発しやすい精油を保つため、添加タイミングが重要。

### ノーブルホップ（欧州4品種）

欧州で数百年の栽培歴を持つ伝統的な4品種。α酸が低く（2〜5%）、ファルネセン等の精油成分がバランスよく含まれ、スパイシー・ハーバル・フローラルな上品な香りが特徴。ラガービール（特にピルスナー）の香りの基準とされる。

| 品種 | 産地 | 主な特徴 |
|------|------|---------|
| **ザーツ（Saaz）** | ボヘミア（チェコ） | ピルスナーの代名詞。土っぽいスパイシー香 |
| **ハラタウ（Hallertau）** | バイエルン（ドイツ） | フローラル・ハーバル。世界最大のホップ産地 |
| **テトナング（Tettnang）** | バーデン＝ヴュルテンベルク（ドイツ） | 繊細でスパイシー |
| **シュパルター（Spalt）** | バイエルン（ドイツ） | マイルドで香り高い |

### ファインアロマホップ

アロマホップの中でも特に品質・繊細さで選抜された品種群。ノーブルホップはその代表格。日本でも「ファインアロマホップ」は試験で問われる用語であり、ノーブルホップと同義または上位概念として扱われる。

## 試験対策ポイント

- **ノーブルホップ4品種をすべて覚える**: ザーツ・ハラタウ・テトナング・シュパルター
- **ザーツ＝チェコ（ボヘミア）**: ピルスナーの香りの源。チェコのザーツ（現サアス）市周辺が産地
- **ハラタウ＝世界最大の産地**: バイエルン北部。ドイツ産ホップの代名詞
- **ビター（高α酸）とアロマ（低α酸・高精油）の使い分け**を理解する
- **ファインアロマホップ**: 検定では「アロマホップの中でも特に香り品質が高い品種」として出題
