# 3度注ぎ：缶ビールをおいしく飲む注ぎ方

## 問題

一般的な缶ビールをおいしく飲むための方法に「3度注ぎ」がある。この説明として誤っているものを次の選択肢より選べ。（2017年）

**選択肢**

- a) グラスは傾けず、水平なところに置く
- b) 最初は泡がグラスの半分程度になるまで勢いよく注ぐ
- c) 2度目はグラスの9割程度になるまで勢いよく注ぐ
- d) 3度目は少しグラスのふちに泡が盛り上がるように慎重に注ぐ

## 正解

**c) 2度目はグラスの9割程度になるまで勢いよく注ぐ**

## 解説

### なぜ正解か

2度目の注ぎは「**勢いよく（×）**」ではなく「**ゆっくり・静かに**」注ぐのが正しい。缶の口をグラスの縁に近づけ、泡をあまり立てないようにしながらグラスの9割程度まで静かに注ぐ。「泡の蓋をそのまま上げていくイメージ」で注ぐのがポイント。「グラスの9割程度まで」という量は合っているが、「勢いよく」という注ぎ方が誤り。

### 背景知識

#### 3度注ぎの手順

| 回 | 操作 | 目的 |
|---|---|---|
| **1度目** | グラスを水平に置き、缶を高めの位置から**勢いよく**注いで泡をグラスの**半分程度**まで作る | 大きな泡を作り、炭酸を一気に放出させる |
| **待つ** | 泡が落ち着くまで（グラスの3分の1程度になるまで）待つ | 粗い気泡が消え、細かくきめ細かい泡に変わる |
| **2度目** | 缶の口をグラスの縁に近づけ、**ゆっくり・静かに**グラスの**9割程度**まで注ぐ | 泡の層を崩さず、液体部分を静かに増やす |
| **待つ** | 泡が落ち着くまで少し待つ | 泡面が安定する |
| **3度目** | 泡がグラスのふちから少し**盛り上がるように慎重に**注いで仕上げる | きめ細かい泡のドームを作る |

#### 3度注ぎの科学的根拠

**なぜ泡が大切か**：
- ビールの泡（泡蓋）はビールが空気に触れるのを防ぎ、**酸化を抑制**する
- 泡があることでビールの香り成分が揮散しにくくなり、香りが保たれる
- きめ細かい泡はビールの苦みをマイルドにし、なめらかな飲み口を生む

**1度目を勢いよく注ぐ理由**：
- 最初に大きな泡（粗い気泡）を作ることで、余分な炭酸ガスを一気に放出させる
- 粗い泡が落ち着くと、タンパク質や苦み成分がネットワークを形成したきめ細かい泡に変化する

**2度目をゆっくり注ぐ理由**：
- 1度目でできた泡の層（泡蓋）を崩さないため
- 新たな粗い泡を作らず、既存の泡の下に液体を静かに加えていく
- 「泡の蓋をそのまま上げていくイメージ」が重要

**3度目で盛り上げる理由**：
- グラスのふちより少し高く盛り上げることで、泡が厚くなり酸化防止効果が高まる
- 見た目の美しさも向上し、飲む楽しみが増す

#### グラスを傾けない理由（選択肢 a との関係）

缶ビールの3度注ぎでは、グラスを**傾けずに水平に置く**のが基本。

- 缶の高さを変えることで勢いを調整するため、グラス自体を動かす必要がない
- 瓶ビールや生ビールのサーバーを使う場合は、グラスを傾けて注ぐ方法もある（グラスに沿わせてゆっくり注ぎ最後に立てる）
- **缶ビール3度注ぎ**と**グラスを使った通常の注ぎ方**の違いを混同しないよう注意

#### 理想的なビールの泡と液体の比率

- 一般的に推奨されるビール：泡の比率は**7:3**（ビール7割・泡3割）
- 泡が少なすぎると酸化しやすく、炭酸も逃げやすい
- 泡が多すぎるとビールの量が減り、風味のバランスが崩れる

### 各選択肢の補足

- **a) グラスは傾けず、水平なところに置く**: 正しい記述。缶ビールの3度注ぎではグラスを水平に置き、缶の高さで勢いを調整する。
- **b) 最初は泡がグラスの半分程度になるまで勢いよく注ぐ**: 正しい記述。1度目は勢いよく注いで泡を半分程度まで作るのが正しい手順。
- **c) 2度目はグラスの9割程度になるまで勢いよく注ぐ**: ✓ **誤り（正解）**。2度目は「勢いよく」ではなく「ゆっくり・静かに」注ぐ。到達量（9割程度）は正しいが注ぎ方が間違い。
- **d) 3度目は少しグラスのふちに泡が盛り上がるように慎重に注ぐ**: 正しい記述。3度目は慎重にふちから盛り上がるように仕上げる。

### 覚え方・関連事項

- **「1度目：勢いよく・2度目：ゆっくり・3度目：慎重に」**：注ぎ方のリズムの変化で覚える
- **「量」と「速さ」を混同しない**：選択肢 c は「量（9割）」は正しいが「速さ（勢いよく）」が誤り。この構造は問006（女性の体内水分量）と同じく「正しい数値＋誤った説明」型の引っかけ
- **缶ビールの高さで勢いを調整**：缶を高く持てば勢いよく、低く（グラス縁に近づけて）持てばゆっくり注げる
- **泡の役割3点**：①酸化防止、②香りの保持、③なめらかな飲み口。これを覚えると「なぜ泡が大切か」という問いにも答えられる
- 「誤っているものを選べ」型は、一部だけ誤っている選択肢（量は正しいが速さが誤り）が正解になる場合が多い。選択肢の全要素を確認する習慣をつける
