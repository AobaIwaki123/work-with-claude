# 煮沸で生成されるホップ由来の苦味物質

## 問題

麦汁煮沸での熱変化により生成されるホップ由来の苦味物質を、次の選択肢より選べ。（2017年）

**選択肢**

- a) α‐アミラーゼ
- b) イソアルファ酸
- c) 酢酸イソアミル
- d) ペプチド

## 正解

**b) イソアルファ酸**

## 解説

### なぜ正解か

ホップをそのまま麦汁に添加しただけでは苦味はほとんど生まれない。ホップに含まれる**アルファ酸（フムロン類）**が麦汁の煮沸（通常60〜90分）によって熱変化を受け、**イソアルファ酸（イソフムロン類）**へと**異性化**されることで初めて苦味を持つ。このイソアルファ酸がビールの苦味の主成分であり、IBU（国際苦味単位）もイソアルファ酸の濃度を基準に算出される。

### 背景知識

#### アルファ酸からイソアルファ酸への変化

```
ホップのアルファ酸（フムロン）
        ↓ 煮沸（熱による異性化）
    イソアルファ酸（イソフムロン）
        → ビールの主要苦味成分
```

| 物質 | 状態 | 苦味 |
|------|------|------|
| アルファ酸 | 煮沸前 | ほぼなし |
| **イソアルファ酸** | **煮沸後** | **あり（ビールの苦味の主成分）** |

異性化率（アルファ酸がイソアルファ酸に変換される割合）は**20〜35%程度**にとどまる。煮沸時間が長いほど、またホップの添加タイミングが早いほど異性化率は上がり、苦味が増す。

#### ホップの主な成分と役割

| 成分 | 役割 |
|------|------|
| **アルファ酸（フムロン類）** | 煮沸でイソアルファ酸に変化→苦味の源 |
| ベータ酸 | 抗菌作用あり、苦味への貢献は少ない |
| 精油成分（テルペン類等） | ホップアロマ（香り）の源。煮沸で揮発するためアロマホップは後添加 |
| タンニン | タンパク質と結合し清澄化に貢献 |

#### ビタリングホップとアロマホップ

ホップの添加タイミングにより目的が変わる：
- **ビタリングホップ**：煮沸開始直後〜60分前に添加。十分に異性化させ苦味を引き出す
- **アロマホップ**：煮沸終了直前〜終了後に添加（ドライホッピング含む）。香り成分を揮発させずに残す

#### 各選択肢の物質の正体

| 物質 | 本来の役割 |
|------|-----------|
| α‐アミラーゼ | デンプンを分解する酵素。糖化工程で活躍（ホップ由来ではない） |
| **イソアルファ酸** | ホップ由来の苦味物質（正解） |
| 酢酸イソアミル | 酵母が発酵時に生成する香り物質（バナナ様の香り）。ヴァイツェンに多い |
| ペプチド | タンパク質の断片。泡の安定性に関係するが苦味物質ではない |

### 各選択肢の補足

- **a) α‐アミラーゼ**: 誤り。糖化工程（マッシング）で麦芽デンプンをマルトースに分解する酵素。ホップ由来でも苦味物質でもない。
- **b) イソアルファ酸**: ✓ 正解。アルファ酸が煮沸により異性化して生成。ビールの苦味の主成分でIBUの算出基準。
- **c) 酢酸イソアミル**: 誤り。酵母が発酵中に生成するエステル系香気物質。バナナ・洋ナシに似た香りでヴァイツェンの特徴的な香り成分。ホップ由来でも苦味物質でもない。
- **d) ペプチド**: 誤り。タンパク質が分解されたアミノ酸の短鎖。麦芽由来で泡の持続性に貢献するが、苦味物質ではない。

### 覚え方・関連事項

- **「アルファ酸→煮沸→イソアルファ酸→苦味」**：この変換の流れを一直線で覚える
- **「イソ」は「異性化」のイソ**：同じ分子式で構造が変わる「異性体（isomer）」から名付けられた
- IBU問題（問題004）と連動：IBUはイソアルファ酸の量で決まる苦さの指標
- α‐アミラーゼは「糖化」、酢酸イソアミルは「発酵香（バナナ）」、ペプチドは「泡」と対応させて整理すると誤答を確実に消せる
- 2017年出題実績あり
