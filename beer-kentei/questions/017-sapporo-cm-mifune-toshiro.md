# 「男は黙ってサッポロビール」CMに出演した俳優

## 問題

かつて、「男は黙ってサッポロビール」のテレビＣＭに出演した俳優を次の選択肢より選べ。

**選択肢**

- a) 三船 敏郎
- b) 石原 裕次郎
- c) 三浦 友和
- d) 渡 哲也

## 正解

**a) 三船 敏郎**

## 解説

### なぜ正解か

「**男は黙ってサッポロビール**」は、**三船敏郎**（みふね としろう、1920〜1997）が出演したサッポロビールのテレビCMのキャッチコピーで、**1970（昭和45）年〜1972（昭和47）年**に放映された。無口で男らしい三船のイメージと「黙って」という言葉が見事に合致し、日本のCM史に残る名作として語り継がれる。

### 背景知識

#### 三船敏郎とサッポロビールCM

三船敏郎は黒澤明監督作品の常連俳優で、国際的にも高い評価を受けた日本映画界の巨星。「羅生門」「七人の侍」「椿三十郎」「用心棒」などで侍の強さと沈黙の美学を体現したイメージが、「男は黙って」というコピーに重なり、強烈な印象を与えた。

| 項目 | 内容 |
|------|------|
| CM放映期間 | 1970（昭和45）年〜1972（昭和47）年 |
| キャッチコピー | 「男は黙ってサッポロビール」 |
| 出演俳優 | 三船敏郎 |
| ブランド | サッポロビール |
| 時代背景 | 大阪万博（1970年）の年、高度成長期の末期 |

#### 各選択肢の俳優とビールCMの関係

選択肢に並ぶ4名は全員、昭和を代表する男優であり、各社ビールCMとの関わりが深いことから混同しやすい。

| 俳優 | 代表作・特徴 | ビールとの関係 |
|------|------------|-------------|
| **三船敏郎** | 黒澤映画（羅生門・七人の侍）、国際的映画スター | サッポロ「男は黙って〜」（1970〜72年） |
| 石原裕次郎 | 日活映画、「太陽の季節」、裕次郎ブランド | ニッカウヰスキーのCMで有名（ビールではない） |
| 三浦友和 | 山口百恵との共演、NHK大河など | ビールCMへの目立った出演なし |
| 渡哲也 | 日活映画、「大都会」「西部警察」 | サッポロビール「男の料理」シリーズ等（別キャンペーン） |

#### 日本のビールCM史における名作コピー

昭和〜平成のビールCMはブランドイメージを確立する上で重要な役割を担った：
- サッポロ「男は黙ってサッポロビール」（1970年〜）三船敏郎
- キリン「一番搾り」シリーズ（1990年代〜）多数の俳優
- アサヒ「スーパードライ」（1987年〜）辛口生ビールとしての定着

### 各選択肢の補足

- **a) 三船敏郎**: ✓ 正解。1970〜1972年のサッポロビールCM「男は黙ってサッポロビール」に出演。黒澤映画の侍イメージと「黙って」というコピーが完璧にマッチ。
- **b) 石原裕次郎**: 誤り。昭和を代表する俳優だが、CMでの代名詞はニッカウヰスキー。サッポロビールの「男は黙って〜」とは無関係。
- **c) 三浦友和**: 誤り。山口百恵のパートナーとして知られる俳優。当該CMへの出演歴はない。
- **d) 渡哲也**: 誤り。石原裕次郎と同じく日活・日本映画の重鎮で、男臭い雰囲気でサッポロビールとも関わりはあるが、「男は黙って〜」のCMに出演したのは三船敏郎。

### 覚え方・関連事項

- **「黙って＝三船」**：無言の侍・国際スター三船敏郎のイメージと「男は黙って」が一致
- 放映年と大阪万博（1970年）をリンク：同じ昭和45年
- 石原裕次郎→ニッカ（ウイスキー）、三船敏郎→サッポロ（ビール）と紐付けておく
- CMのキャッチコピー「男は黙ってサッポロビール」は現在でも広告コピーの名作として引用される
