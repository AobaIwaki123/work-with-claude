# 仕込工程でつくられる「おかゆ」状のもの──マイシェ

## 問題

ビールの仕込工程において、粉砕された麦芽と温水を混ぜ合わせてつくられる「おかゆ」状のものを何というか、次の選択肢より選べ。（2014年）

**選択肢**

- a) モルトエキス
- b) モルトペースト
- c) ブルッフ
- d) マイシェ

## 正解

**d) マイシェ**

## 解説

### なぜ正解か

**マイシェ（Maische）**はドイツ語で、粉砕した麦芽（モルト）を温水と混合した**おかゆ状の醪（もろみ）**のことを指す。英語では**マッシュ（Mash）**に相当する。仕込槽や仕込釜に入れられた麦芽は最初は固形物として認識できるが、攪拌しながら適切な温度に保つことでデンプンとタンパク質が徐々に分解され、液状になっていく。

### 背景知識

#### マイシェから麦汁へ

```
粉砕麦芽 ＋ 温水
        ↓ 投入・混合
    【マイシェ】（おかゆ状）
        ・50℃：タンパク休止（プロテアーゼ活性）
        ・65℃：糖化（β‐アミラーゼ主体）
        ・75℃：糖化終了・マッシュアウト
        ↓ 濾過（ロイタリング）
    【麦汁】（清澄な糖液）
```

#### マイシェの状態変化

| 段階 | 状態 |
|------|------|
| 投入直後 | 麦芽の固形物が見える粗いおかゆ状 |
| 糖化中（攪拌・保温） | 徐々に液化が進む |
| 糖化終了後 | 液体（麦汁）＋固形残渣（麦殻） |
| 濾過後 | 清澄な麦汁のみ（固形分は除去） |

#### 各選択肢の用語の本来の意味

| 用語 | 本来の意味 |
|------|-----------|
| **マイシェ** | ドイツ語。麦芽＋温水のおかゆ状醪＝正解 |
| モルトエキス | 麦芽を煮出して濃縮した液体。ホームブルーイング等で原料として使う市販品 |
| モルトペースト | 一般的な醸造用語としては使われない造語 |
| ブルッフ | 麦汁煮沸時に生成されるタンパク質の凝固物（問題018参照）。マイシェとは別の工程・別の産物 |

### 各選択肢の補足

- **a) モルトエキス**: 誤り。モルトエキスは麦芽エキスとも呼ばれ、麦汁を濃縮した製品。仕込工程のおかゆ状の状態を指す言葉ではない。
- **b) モルトペースト**: 誤り。醸造の正式用語ではない造語。「ペースト状」というイメージから引っかかりやすいが、正式名称はマイシェ。
- **c) ブルッフ**: 誤り。ブルッフは麦汁**煮沸**工程で生成されるタンパク質の凝固物で、マイシェ（糖化工程の醪）とは全く異なる。問題018で扱った用語。
- **d) マイシェ**: ✓ 正解。粉砕麦芽＋温水のおかゆ状の醪。英語名はマッシュ（Mash）。

### 覚え方・関連事項

- **「マイシェ＝マッシュ（Mash）のドイツ語版」**：英語のマッシュポテトの「マッシュ」と同語源
- 「おかゆ」というキーワードが試験に出たら迷わずマイシェ
- 問題015（製造工程の順序：マイシェ→麦汁→若ビール→ビール）と連動
- 問題014（マイシェの温度管理：50℃・65℃・75℃）と連動
- ブルッフ（問題018）との混同注意：同じ仕込工程でもマイシェは**糖化段階の醪**、ブルッフは**煮沸段階の凝固物**
- 2014年出題実績あり
