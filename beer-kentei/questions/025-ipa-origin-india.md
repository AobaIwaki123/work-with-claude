# IPAはどこへ輸送するために開発されたか

## 問題

イギリスで誕生したIPAはどこに輸送されるために開発されたものか、その行先を、次の選択肢より選べ。（2016年）

**選択肢**

- a) イスタンブール
- b) イスラエル
- c) インド
- d) 西インド諸島

## 正解

**c) インド**

## 解説

### なぜ正解か

**IPA（India Pale Ale）**は名称そのものに答えが含まれており、**India（インド）**への輸送を目的として開発されたビアスタイルである。18世紀末、イギリスから植民地インドへのビール輸送には赤道を越える長距離の航海（数ヶ月）が必要で、通常のビールでは途中で劣化・腐敗してしまった。そこでホップの防腐効果を最大限に活用するために**ホップを大量投入**し、さらに**アルコール度数を高め（4.5〜7.0%程度）**て保存性を高めたビールが生まれた。これがIPAの起源とされる。

### 背景知識

#### IPAの誕生とイギリス植民地時代

18世紀のイギリスは東インド会社を通じてインドを植民地支配しており、現地に駐在する兵士・官僚・商人たちへの物資補給が必要だった。ビールも重要な補給品の一つだったが、赤道を越える長期航海中に腐敗する問題があった。

**解決策：ホップ大量投入＋高アルコール度数**
- **ホップのイソアルファ酸**には抗菌・防腐作用がある
- **高アルコール**も微生物の増殖を抑制する
- 長旅の振動・温度変化の中で熟成が進み、むしろ現地到着時に飲み頃になったという説もある

#### IPAの特徴

| 項目 | 内容 |
|------|------|
| 正式名称 | India Pale Ale |
| 発酵方式 | 上面発酵（エール） |
| ABV | 4.5〜7.0%（やや高め） |
| IBU | 40〜70以上（強い苦味） |
| 特徴 | 強いホップの苦味・香り、やや高いアルコール |
| 誕生時期 | 18世紀末 |
| 誕生地 | イギリス |

#### IPAの派生スタイル

| スタイル | 特徴 |
|---------|------|
| イングリッシュIPA | 原点。土っぽいホップ香、やや抑えめの苦味 |
| アメリカンIPA | 柑橘・松脂系のホップ香が強烈。西海岸発祥 |
| ダブルIPA（DIPA・IIPA） | ABV 7.5%以上、IBU 60以上の超強烈バージョン |
| セッションIPA | ABV 4%以下でホップ香を楽しむ低アルコール版 |
| ニューイングランドIPA（NEIPA） | 濁り系・柔らかい口当たり・フルーティー |

#### ホップの防腐作用（問題012との連動）

ホップのアルファ酸が煮沸でイソアルファ酸に変化し苦味をもたらすが、このイソアルファ酸には**グラム陽性菌に対する抗菌作用**もある。IPAのホップ大量投入は、この防腐機能を意図的に最大化したものといえる。

### 各選択肢の補足

- **a) イスタンブール**: 誤り。「I」で始まる地名として紛らわしいが、IPAとは無関係。イスタンブールはオスマン帝国の首都（現トルコ）。
- **b) イスラエル**: 誤り。同様に「I」で始まる地名の引っかけ。IPAの誕生と無関係。
- **c) インド**: ✓ 正解。IPA＝**India** Pale Ale。18世紀末にイギリスからインドへの長期輸送に耐えるよう開発された。
- **d) 西インド諸島**: 誤り。カリブ海の島々で、イギリスの植民地でもあった。「インド」という言葉が含まれるため紛らわしいが、西インド諸島≠インド（南アジア）。IPAはインド亜大陸向けに開発された。

### 覚え方・関連事項

- **IPA＝India Pale Ale**：頭文字を展開すれば「インド」が答え
- 西インド諸島（Caribbean）はカリブ海の島々。インド亜大陸とは全く別の地域
- **ホップ大量投入＋高ABV＝防腐のため**という開発目的のストーリーで覚える
- 問題006（イングリッシュブラウンエール）と対比：ブラウンエールはホップ控えめ、IPAはホップ最大量
- 問題012（イソアルファ酸・ホップの防腐作用）と連動：ホップの抗菌作用がIPAの防腐に活用された
- 2016年出題実績あり
