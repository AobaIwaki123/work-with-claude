# 日本のビール文化を支える著名な注ぎ手とビアスタンド

## 問題

「灘コロンビア」「ビアライゼ'98」「銀座ライオン」「キリンシティ」「ビールスタンド重富」。各店に共通する特徴として最も適しているものを、次の選択肢より選べ。（2017年）

**選択肢**

- a) 有名な注ぎ手が輩出もしくは在籍している
- b) 常時20種類以上のビールを提供している
- c) マイクロブルワリーを併設している
- d) 大手ビール会社の子会社である

## 正解

**a) 有名な注ぎ手が輩出もしくは在籍している**

## 解説

### なぜ正解か

5店舗はいずれも、ビール好きのあいだで名の知られた「注ぎ手（ビールをサーブする職人）」と強く結びついている。

| 店名 | 注ぎ手 |
|------|--------|
| 灘コロンビア（兵庫・灘） | 新井徳司 氏 |
| ビアライゼ'98（東京・神保町） | 松尾光平 氏 |
| 銀座ライオン（東京・銀座） | 海老原清 氏 |
| キリンシティ（各地） | 松本宏 氏 |
| ビールスタンド重富（広島） | 重富寛 氏 |

これらの注ぎ手はビールの泡立て・注ぎ方・温度管理などに独自の技術・哲学を持ち、「その人の注ぐビールを飲みに行く」という文化を生み出している。5店舗に共通する最大の特徴は種類の多さでも設備でもなく、この「人」の存在である。

### 背景知識

#### 日本における「注ぎ手」文化の意義

欧米では醸造所・ブランドそのものへの注目が強いが、日本では「どう注ぐか」「誰が注ぐか」というサービス側の技術も重視される独自の文化がある。同じビールでもグラスの種類・角度・泡の比率・温度によって風味が大きく変わるため、熟練した注ぎ手の存在は付加価値として機能する。

#### 各店・注ぎ手のプロフィール（概要）

- **新井徳司氏（灘コロンビア）**: 1949年、東京駅近くで開業した老舗。注いだ生ビールの泡がきめ細かく「楊枝が立つ」と絶賛された伝説的注ぎ手。その技術は弟子の松尾光平氏に継承されており、師弟関係が有名。

- **松尾光平氏（ビアライゼ'98）**: 東京・神保町の書店街に位置するビアバー。新井徳司氏の弟子として注ぎ方を継承。ドイツ流の泡立てにこだわり、ビール文化の啓発にも積極的。

- **海老原清氏（銀座ライオン）**: サッポロビールが運営する銀座の老舗ビアホール。「海老原清が注ぐ日を目指して来店するファンが多い」と言われるほどの人気注ぎ手。

- **松本宏氏（キリンシティ）**: キリンビールが展開するビアレストランチェーン「キリンシティ」在籍。「松本ラガーが飲みたい」とファンが集まる存在。「3度注ぎ」の技法で有名。

- **重富寛氏（ビールスタンド重富）**: 広島のビールスタンドを経営。何種類もの注ぎ方が選べるスタイルで知られ、「二度注ぎ」など独自の注ぎ技術を体系化。YouTubeなどでの発信でも知られる。

#### ビールの注ぎ方と泡の役割

ビールにおける泡（ヘッド）は単なる見た目ではなく、以下の機能を持つ：

- **酸化防止**: 泡がビール表面を覆い、空気（酸素）との接触を遮断する
- **炭酸ガス保持**: 炭酸が逃げるのを抑え、爽快感を維持する
- **香り閉じ込め**: 泡層がアロマを保持し、飲むたびに香りが広がる
- **見た目・食欲**: 白い泡はビールの新鮮さと品質の視覚的シグナル

理想的な泡の量は全体の約2〜3割とされるが、店や注ぎ手によって哲学が異なる。

### 各選択肢の補足

- **a) 有名な注ぎ手が輩出もしくは在籍している**: ✓ 正解。5店舗はいずれも著名な注ぎ手と結びついており、ビール好きのあいだでその名が知られている。
- **b) 常時20種類以上のビールを提供している**: 誤り。多品種提供はクラフトビアバーの特徴として語られるが、これら5店の「共通する最大の特徴」ではない。特にビールスタンド重富のような店は品種よりも注ぎ方に特化している。
- **c) マイクロブルワリーを併設している**: 誤り。5店のいずれも自家醸造（ブルーパブ）を主な特徴としていない。銀座ライオン・キリンシティは大手ビール会社の運営であり、自社醸造とは異なる。
- **d) 大手ビール会社の子会社である**: 誤り。銀座ライオン（サッポロ）・キリンシティ（キリン）は大手系列だが、灘コロンビア・ビアライゼ'98・ビールスタンド重富は独立系であり、全店に共通する特徴ではない。
