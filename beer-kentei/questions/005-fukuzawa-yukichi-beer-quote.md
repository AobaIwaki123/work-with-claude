# 「其味至て苦けれど胸膈を開く」──福沢諭吉とビールの名言

## 問題

ビールについて「其味至て苦けれど胸膈を開く為に妙なり」という言葉を残した偉人を次の選択肢より選べ。

**選択肢**

- a) 緒方 洪庵
- b) 川本 幸民
- c) 中江 兆民
- d) 福沢 諭吉

## 正解

**d) 福沢 諭吉**

## 解説

### なぜ正解か

福沢諭吉は**片山淳之助**という別名義で著した『**西洋衣食住**』（1867年）の中でビールを紹介し、「其味至て苦けれど胸膈を開く為に妙なり」と記した。意味は「その味は非常に苦いが、腹を割って話す（打ち解ける）ために絶妙である」。苦みを正直に認めつつも、ビールのコミュニケーション効果を的確に表現した言葉として知られる。

### 背景知識

#### 福沢諭吉と西洋文化の紹介

福沢諭吉（1835〜1901）は慶應義塾の創設者・啓蒙思想家として名高いが、幕末期には**片山淳之助**という筆名で西洋の生活文化を紹介する著作を多数刊行した。『西洋衣食住』（1867年）はその代表作の一つで、衣・食・住にわたる西洋の習慣を日本人向けにわかりやすく解説した書物である。

#### 「胸膈を開く」の意味

「胸膈（きょうかく）」とは胸と横隔膜の間を指す言葉で、転じて**心の内側・本音**を意味する。「胸膈を開く」＝腹を割って話す・打ち解ける・友人になる、という意。苦みというハードルを越えた先に社交的な効用がある、というビールの本質を見事に言い表している。

#### 幕末・明治期の洋学者とビール

| 人物 | ビールとの関係 |
|------|-------------|
| 福沢諭吉 | 『西洋衣食住』でビールを「胸膈を開く」と紹介 |
| 川本幸民 | 1853年頃に日本で初めてビールを醸造した蘭学者 |
| 緒方洪庵 | 天然痘ワクチン普及などで知られる蘭学者・医師 |
| 中江兆民 | フランス思想を紹介した自由民権運動の思想家 |

#### 日本のビール史における位置づけ

1853年の川本幸民による試醸から、1869年の横浜でのビール醸造所設立、1877年の札幌麦酒醸造所（現サッポロビール）設立へと続く流れの中で、福沢諭吉の著作はビールを**文化・習慣として日本人に広める**役割を担った。

### 各選択肢の補足

- **a) 緒方洪庵**: 江戸末期の蘭学者・医師。天然痘ワクチン接種の普及に貢献した人物で、ビール関連の記述は特に知られていない。
- **b) 川本幸民**: 蘭学者で、1853年頃に日本で初めてビールを醸造したとされる人物。ビールと深く関わるが、この名言とは無関係。混同しやすいため要注意。
- **c) 中江兆民**: ルソーの思想を日本に紹介した「東洋のルソー」と称される自由民権運動の思想家。ビール関連の著述は特に知られていない。
- **d) 福沢諭吉**: ✓ 正解。別名・片山淳之助として著した『西洋衣食住』（1867年）でビールを紹介し、この名言を残した。

### 覚え方・関連事項

- **「苦いけど心を開く」＝福沢諭吉**：一万円札の人物が日本にビール文化を紹介したと覚える
- 著書名：**『西洋衣食住』**、筆名：**片山淳之助**（福沢諭吉の別名義）
- **川本幸民**（初醸造）と**福沢諭吉**（文化紹介）は混同しやすいのでセットで整理する
  - 川本幸民 → **作った人**（1853年、日本初醸造）
  - 福沢諭吉 → **広めた人**（1867年、著作でビール紹介）
