# メルツェン：オクトーバーフェストのために仕込まれるビール

## 問題

ドイツ・バイエルンの州都ミュンヘンで行われ、世界中から毎年600万人以上が来場するオクトーバーフェスト。この祭典のために仕込まれるビールを次の選択肢より選べ。（2013）

**選択肢**

- a) クリーク
- b) ケルシュ
- c) スリースレッド
- d) メルツェン

## 正解

**d) メルツェン**

## 解説

### なぜ正解か

オクトーバーフェストで提供される伝統的なビールは**メルツェン（Märzen）**。ドイツ語で「3月（März）のビール」を意味し、**冷蔵技術が普及する以前の時代に3月に仕込んで夏を越え、秋のオクトーバーフェストに合わせて飲み頃を迎える**という醸造サイクルから生まれたスタイル。色がやや濃く（琥珀〜銅色）、アルコール度数もやや高め（5.8〜6.3%程度）、モルトの甘みが豊かな飲み応えのあるラガービール。

### 背景知識

#### オクトーバーフェストの歴史

- **1810年10月12日**：バイエルン王国のルートヴィヒ王太子（後のルートヴィヒ1世）とザクセン＝ヒルトブルクハウゼン公国の公女**テレジア**の結婚式を祝う祭典が開催された
- 会場はミュンヘン郊外の城壁前の緑地。以来この地は**テレジエンヴィーゼ（Theresienwiese＝テレジアの緑地）**と呼ばれ、現在も開催地となっている
- 翌年以降も競馬を軸とした祭典を継続すると発表し、毎年恒例の祭りとして定着
- やがて農業品評会やビール提供が加わり、現在の形に発展した

#### メルツェン（Märzen）の特徴

| 項目 | 内容 |
|---|---|
| 仕込み時期 | **3月**（ドイツ語でMärz） |
| 色 | 琥珀〜銅色（アンバー系） |
| アルコール度数 | 5.8〜6.3%程度 |
| 特徴 | モルトの甘みが豊か、しっかりした飲み応え |
| 熟成期間 | 仕込みから秋まで低温で長期熟成（ラガリング） |
| スタイル分類 | ドイツ式ラガー |

**なぜ3月に仕込むのか**：冷蔵技術がなかった時代、夏の高温ではビール醸造ができなかった。そこで春の訪れる前の3月に仕込み、氷室（アイスケラー）で夏の間貯蔵・熟成させ、秋の収穫祭シーズンに飲み頃を迎えるという年間サイクルが確立された。

#### オクトーバーフェストビールの現代的変化

現代のオクトーバーフェストでは、伝統的なメルツェンに加えて、より淡色の**ヘルスビール（Helles）**も広く提供されるようになっている。ミュンヘンの6大醸造所（ホフブロイ・レーベンブロイ・パウラーナー・アウグスティナー・シュパーテン・ハッカー＝プショール）が専用テントを設け、それぞれの「フェストビール」を提供する。

#### 選択肢のビアスタイル解説

**ケルシュ（Kölsch）**：
- ドイツ・ケルン（Köln）の地ビール
- **エールとラガーの中間的な製法**：上面発酵後に低温熟成するハイブリッドスタイル
- 淡色・軽快・やや苦みがある
- ケルン市内の特定醸造所のみが名乗れる地理的保護スタイル
- 専用グラス「シュタンゲ」（細長い円筒形200ml）で提供される（問004と関連）

**クリーク（Kriek）**：
- **ベルギー産のランビック（自然発酵）ビール**にサクランボ（クリーク）を加えて再発酵させたフルーツビール
- 強い酸味とチェリーの風味が特徴
- ランビックはブリュッセル近郊のゼンヌ川流域に固有の野生酵母・乳酸菌による自然発酵で醸造される

**スリースレッド（Three Threads）**：
- 18世紀のイギリスで飲まれていた**複数のビールを混ぜた飲み物**
- 異なる樽のビールを3種類（三つのスレッド＝糸口）混ぜて提供したことが名前の由来
- これがポーターの前身となったとする説がある（醸造家が一つの樽でこの味を再現しようとしてポーターが誕生）

### 各選択肢の補足

- **a) クリーク**: 誤り。ベルギー産のサクランボ使用フルーツランビック。オクトーバーフェストとは全く関係のないベルギーの伝統スタイル。
- **b) ケルシュ**: 誤り。ケルン地方のハイブリッドビール。バイエルン・ミュンヘンではなくケルンの地ビールであり、オクトーバーフェストでは提供されない。
- **c) スリースレッド**: 誤り。18世紀イギリスの混合飲料で、ポーター誕生との関連で知られる歴史的な概念。ドイツのビール祭りとは無関係。
- **d) メルツェン**: ✓ 正解。「3月仕込み・秋に飲み頃」のドイツ伝統ラガー。オクトーバーフェストの象徴的なビール。

### 覚え方・関連事項

- **メルツェン＝März（3月）＋en**：語源から「3月のビール」と直結して覚える
- **「3月仕込み→夏に貯蔵→10月のオクトーバーフェストで飲む」**：製造サイクルの流れを時系列で覚える
- **テレジエンヴィーゼ**：「テレジア（花嫁）の緑地」。人名＋緑地の組み合わせで会場名を覚える
- 問004（マース＝1Lジョッキ）と本問（メルツェン＝ビールの種類）はオクトーバーフェスト関連の2大頻出テーマ。セットで学習する
- **ケルシュとメルツェンの混同注意**：どちらもドイツのビールだが、ケルシュはケルン・上面発酵系、メルツェンはミュンヘン・ラガー系で産地・製法・スタイルがすべて異なる
