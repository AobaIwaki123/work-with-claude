# ホップの植物的特徴──科・草丈・使用部位・球花

## 問題

ホップに関する説明として正しいものを、次の選択肢より選べ。（2017年）

**選択肢**

- a) バラ科のつる性の植物である
- b) 収穫期には1mほどの長さに成長する
- c) ビール醸造には雄株の葉を使用する
- d) ホップの「球花」は「毬花」などとも表記される

## 正解

**d) ホップの「球花」は「毬花」などとも表記される**

## 解説

### なぜ正解か

ビール醸造に使うホップの果実は生育すると松かさ（松ぼっくり）に似た球状の形態になることから**「球花（きゅうか）」**と呼ばれ、**「毬果（きゅうか）」「毬花（まりか）」**と表記されることもある。これが正しい説明である。

### 背景知識

#### ホップの植物学的分類

| 項目 | 正しい情報 |
|------|-----------|
| 科 | **アサ科**（Cannabaceae）※バラ科ではない |
| 属 | **カラハナソウ属**（Humulus）|
| 学名 | *Humulus lupulus* |
| 生育型 | **つる性**の多年草 |
| 収穫期 | 8〜9月（北半球） |
| 草丈（収穫期） | **約7m**（1mではない） |

#### 選択肢の誤り一覧

| 選択肢 | 誤りの内容 | 正しい情報 |
|--------|-----------|-----------|
| a | バラ科 | **アサ科** |
| b | 1m | **7m** |
| c | 雄株の葉 | **雌株の果実（球花）** |
| d | 球花＝毬花 | **✓ 正しい** |

#### ホップの使用部位：雌株の球花

ホップは雌雄異株（雌株と雄株が別の個体）であり、醸造に使用するのは**未授精の雌株の果実（球花）**である。雌株が授精すると種子が形成され、苦味成分の含有量が低下するため、商業栽培では雄株を排除して雌株のみを栽培する。

#### 球花の構造と醸造上の役割

```
球花（毬花）
├── 苞葉（ブラクト）：松かさ状の葉片
└── ルプリン腺（黄色い粉状の腺体）
    ├── アルファ酸 → 煮沸でイソアルファ酸に変化 → 苦味（問題012参照）
    ├── ベータ酸 → 抗菌作用
    └── 精油成分 → ホップアロマ（香り）
```

ルプリンはホップの球花の根元に付着する黄色い粉状の腺体で、苦味・香り成分が凝縮されている。

#### 日本のホップ産地

日本では主に**岩手県遠野市**が国内最大のホップ産地として知られる。遠野は「ホップの里」として、クラフトビール産業との連携でも注目されている。

### 各選択肢の補足

- **a) バラ科のつる性の植物である**: 誤り。ホップは**アサ科カラハナソウ属**。バラ科ではない。「つる性」という部分は正しいが、科の部分が誤り。
- **b) 収穫期には1mほどの長さに成長する**: 誤り。収穫期（8〜9月）には**7m程度**まで成長する。1mは著しく過小な数値。
- **c) ビール醸造には雄株の葉を使用する**: 誤り。「雄株」も「葉」も誤り。使用するのは**雌株の果実（球花）**。雄株は授精を防ぐために栽培から除外される。
- **d) ホップの「球花」は「毬花」などとも表記される**: ✓ 正解。松かさ状の形状から「球花」と呼ばれ、「毬果」「毬花」とも表記される。

### 覚え方・関連事項

- **「ホップ＝アサ科・7m・雌株の球花」**：三点セットで覚える
- 「バラ科」は間違い。アサ科には大麻（Cannabis）も属しており、ホップはその近縁植物
- 草丈の数字：**7m**（7階建ての建物に匹敵）は「意外と大きい」と記憶に残りやすい
- 球花の中のルプリン（黄色い粉）が苦味・香りの源：問題012（イソアルファ酸）と連動
- 収穫期の**8〜9月**も頻出：夏の終わりに収穫されるホップのイメージ
- 2017年出題実績あり
