# 「ラガー」はドイツ語で何を意味するか

## 問題

ラガービールの「ラガー」はドイツ語の「Lagern」を語源とするが、どのような意味があるか、適切なものを次の選択肢より選べ。（2019年）

**選択肢**

- a) 熱処理
- b) 濾過
- c) 貯蔵
- d) ラグビー選手

## 正解

**c) 貯蔵**

## 解説

### なぜ正解か

「**Lagern（ラーゲルン）**」はドイツ語で「**貯蔵する・蓄える**」を意味する動詞である。ラガービールは発酵後に低温（0〜4℃程度）で数週間〜数ヶ月にわたって**貯蔵・熟成（ラグリング）**させることで、雑味が取れてクリアですっきりとした味わいになる。この貯蔵工程こそがラガーの名前の由来であり、醸造上の最大の特徴でもある。

### 背景知識

#### ラガーの醸造工程

| 工程 | 内容 |
|------|------|
| 発酵 | 下面発酵酵母を使用、低温（5〜12℃）でゆっくり発酵 |
| **ラグリング（貯蔵・熟成）** | **0〜4℃で数週間〜数ヶ月保管。Lagern（貯蔵）がここに由来** |
| 効果 | ダイアセチル（バター臭）などの副産物が減少、味がまろやかになる |

#### エールとラガーの比較

| 項目 | エール（上面発酵） | ラガー（下面発酵） |
|------|-----------------|-----------------|
| 酵母の位置 | 発酵液の上部に集まる | 発酵タンクの底に沈む |
| 発酵温度 | 15〜25℃（高め） | 5〜12℃（低め） |
| 貯蔵期間 | 比較的短い | 長期低温熟成（Lagern） |
| 風味 | フルーティー・複雑 | すっきり・クリア |
| 代表スタイル | ペールエール、スタウト | ピルスナー、ヘレス、ボック |

#### ドイツ語のビール関連用語

| ドイツ語 | 読み | 意味 |
|---------|------|------|
| **Lagern** | ラーゲルン | 貯蔵する |
| Bier | ビア | ビール |
| Hefe | ヘーフェ | 酵母 |
| Malz | マルツ | 麦芽 |
| Hopfen | ホップフェン | ホップ |
| Weizen | ヴァイツェン | 小麦 |

#### 「ラガー」という語の英語への定着

ドイツ移民がアメリカに持ち込んだラガー醸造技術により、19世紀後半から「Lager」という語が英語圏でも定着。現在では世界で最も消費されるビアスタイルであり、日本の大手ビールメーカーが製造するビールもほぼすべてラガー（厳密にはピルスナータイプ）に分類される。

### 各選択肢の補足

- **a) 熱処理**: 誤り。熱処理（パストゥリゼーション）はビールの殺菌工程を指す別の概念。日本では「熱処理ビール」と「生ビール（非熱処理）」の区分で使われる用語。
- **b) 濾過**: 誤り。濾過はビールから酵母・タンパク質を除去する工程。Lagernとは無関係。
- **c) 貯蔵**: ✓ 正解。Lagern＝貯蔵する。低温での長期熟成工程がラガーの名の由来。
- **d) ラグビー選手**: 誤り。英語の「rugger（ラガー）」は確かにラグビー選手を意味するが、ビールのLager（ラガー）とは語源が全く異なる。引っかけとして設定された誤答。

### 覚え方・関連事項

- **「ラガー＝貯蔵」**：ドイツ語Lagern→貯蔵→低温熟成→すっきりした味、という流れで覚える
- 「倉庫（storage）」を意味するドイツ語**Lager（ラーガー）**も同じ語根。軍事用語「弾薬庫（Munitionslager）」にも同じ語が使われる
- 選択肢dの「ラグビー選手」は英語の綴りが"rugger"で、ビールの"lager"とは別物
- 公式テキスト95ページ（2022年5月改訂版）出典。2019年出題実績あり
- 関連問題：エール vs ラガーの発酵温度・酵母位置の違いもセットで押さえておく
