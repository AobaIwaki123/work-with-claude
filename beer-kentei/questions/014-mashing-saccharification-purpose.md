# 糖化（マッシング）：デンプンを酵母が使える糖に変える工程

## 問題

糖化の目的として最も適切なものを次の選択肢より選べ。（2017年）

**選択肢**

- a) 麦汁を殺菌するため
- b) ビールの甘味を引き出すため
- c) 麦芽内にタンパク質分解酵素を生成するため
- d) デンプンをビール酵母が取り込める大きさの糖に分解するため

## 正解

**d) デンプンをビール酵母が取り込める大きさの糖に分解するため**

## 解説

### なぜ正解か

ビール酵母はデンプン（多糖類）を直接取り込んでアルコール発酵に使うことができない。酵母が利用できるのは単糖（グルコース）や二糖（マルトース）などの小さな糖分子である。糖化（マッシング）は、麦芽（モルト）中の**アミラーゼ酵素**を温水中で活性化させ、デンプンをこれらの発酵性糖に分解する工程である。糖化によって生じた糖分を含む液体が**麦汁（ワート）**となり、後の発酵工程で酵母のエサになる。

### 背景知識

#### ビール醸造の主要工程と糖化の位置づけ

```
麦芽粉砕 → 糖化（マッシング） → ろ過（麦汁分離） → 煮沸（ホップ添加）
→ 冷却 → 発酵 → 熟成 → ろ過 → 充填
```

糖化は仕込みの中核工程で、最終的なビールの甘味・コク・アルコール度数を左右する。

#### 糖化で働く主な酵素

| 酵素 | 別名 | 主な働き | 至適温度 |
|------|------|---------|---------|
| α-アミラーゼ | 液化酵素 | デンプン鎖をランダムに切断し液化 | 70〜75℃ |
| β-アミラーゼ | 糖化酵素 | デンプン末端からマルトースを切り出す | 60〜65℃ |
| プロテアーゼ | タンパク質分解酵素 | タンパク質をアミノ酸・ペプチドに分解 | 45〜55℃ |

**β-アミラーゼ**が主に**マルトース（麦芽糖）**を生成する。マルトースはビール酵母が最も好んで利用する発酵性糖であり、アルコールと炭酸ガス（CO₂）に変換される。

#### 糖化温度とビールの味わいの関係

糖化温度によって、α-アミラーゼとβ-アミラーゼの活性比率が変わり、生成される糖の種類が変化する：

- **低温糖化（62〜65℃）**: β-アミラーゼが優勢 → 発酵性糖（マルトース）が多い → ドライでキレのあるビール
- **高温糖化（68〜72℃）**: α-アミラーゼが優勢 → デキストリン（非発酵性糖）が多い → ボディがある甘みのあるビール

クラフトビール醸造では、この温度を意図的に操作してビールのキャラクターを設計する。

#### 麦芽製造（モルティング）との関係

糖化で働く酵素は醸造所で加えるのではなく、**製麦（モルティング）工程で大麦の中に生成される**。大麦を水に浸けて発芽させる過程でアミラーゼなどの酵素が活性化・生成される。これが「大麦をそのまま使わず麦芽（モルト）にする」理由の一つである。

### 各選択肢の補足

- **a) 麦汁を殺菌するため**: 誤り。殺菌（パスチャリゼーション）は**煮沸工程**（ホップを加えて麦汁を沸騰させる工程）や充填後の加熱処理で行われる。糖化は60〜75℃程度の温水で行われ、完全な殺菌温度には達しない。
- **b) ビールの甘味を引き出すため**: 誤りではないが不正確。糖化で生じるデキストリン（非発酵性糖）はビールにボディと甘みを与えるが、それは糖化の**副次的な結果**であり「目的」として最も適切ではない。主目的は酵母が利用できる発酵性糖の生成。
- **c) 麦芽内にタンパク質分解酵素を生成するため**: 誤り。タンパク質分解酵素（プロテアーゼ）は**製麦（発芽）工程**で生成される。糖化工程ではすでに存在する酵素を活性化・利用するのであり、新たに生成するわけではない。
- **d) デンプンをビール酵母が取り込める大きさの糖に分解するため**: ✓ 正解。糖化の本質的な目的。アミラーゼがデンプン→マルトース・グルコース等に分解し、酵母が発酵に使える糖を生成する。

### 覚え方・関連事項

- **糖化＝デンプン→糖（酵母のエサ作り）** の一言で本質を押さえる
- 酵素は麦芽製造時に生成済み。糖化は「酵素を働かせる」工程
- **β-アミラーゼ→マルトース生成→酵母が発酵** のつながりで覚える
- 温度と味わいの関係：「低温→ドライ（発酵性糖↑）」「高温→ボディ（デキストリン↑）」
- 殺菌は糖化ではなく**煮沸工程**。混同しないこと
