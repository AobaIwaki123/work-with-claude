# 二条大麦と六条大麦：特徴と製麦の基礎知識

## 問題

ビール原料に使用される大麦に関する記述のうち、誤っているものを次の選択肢より選べ。

**選択肢**

- a) プラネットはヨーロッパ以外にオーストラリアでも代表的な品種である
- b) 一般的に二条大麦は六条大麦に比べ、穀粒が小粒で穀皮が厚い傾向がある
- c) 製麦工程での浸麦終了時点の大麦の水分含量は40〜45％である
- d) 糊粉層は胚乳の一部であり、酵素の合成・分泌や発芽に必要なホルモンの伝達に関与する

## 正解

**b) 一般的に二条大麦は六条大麦に比べ、穀粒が小粒で穀皮が厚い傾向がある**

## 解説

### なぜ正解か

選択肢 b) は**逆の記述**であるため誤り。正しくは、**二条大麦は六条大麦に比べて穀粒が大きく、穀皮が薄い**傾向がある。

- 二条大麦：穀粒が**大きい**・穀皮が**薄い**・デンプン含量が**多い** → ビール醸造に最適
- 六条大麦：穀粒が**小さい**・穀皮が**厚い**・タンパク質・酵素力が**高い**

穀皮が厚いと麦汁の苦み・渋みに影響するため、ビール醸造では穀皮の薄い二条大麦が世界的な主流となっている。

### 背景知識

#### 二条大麦と六条大麦の違い

「条数」とは、穂の列数を指す。穂軸の1節から伸びる小穂が2列のものが二条、6列のものが六条。

| 比較項目 | 二条大麦 | 六条大麦 |
|---|---|---|
| 穀粒の大きさ | 大きい（均一） | 小さい（不均一になりやすい） |
| 穀皮の厚さ | 薄い | 厚い |
| デンプン含量 | 多い | 少ない |
| タンパク質含量 | 少ない | 多い |
| 酵素力 | 低め | 高い |
| ビール醸造への適性 | 高い（現在の主流） | やや低い（補助原料使用時に有利） |
| 主な産地 | ヨーロッパ、オーストラリア、北米 | 日本、北米の一部 |

> 日本では古くから六条大麦が栽培されてきたが、ビール醸造向けには二条大麦を輸入・国産化している。

#### 代表的な二条大麦品種

- **プラネット（Planet）**：ヨーロッパ（特にドイツ・チェコ）とオーストラリアで広く栽培される醸造用品種。均一な粒揃いと高いエキス収量が特徴。
- **スカーレット（Scarlett）**：ヨーロッパ産の代表品種。安定した品質で世界的に使用される。
- **ゴールデンプロミス（Golden Promise）**：スコットランドの伝統品種。シングルモルトウイスキーや一部クラフトビールに使用される。
- **はるな二条**：日本国内で開発された醸造用二条大麦品種。

#### 製麦工程と浸麦（ちんばく）

製麦（モルティング）は大麦を麦芽（モルト）に加工する工程。主な流れは以下の通り。

```
大麦 → 浸麦（水分を吸わせる） → 発芽（根・葉芽を出させる） → 焙燥（乾燥・焙煎） → 麦芽
```

**浸麦（steeping）**：
- 大麦を水に浸して水分を吸収させる工程
- 目的：発芽に必要な水分と酸素を供給する
- 浸麦開始時の大麦の水分含量：約**12〜15%**
- **浸麦終了時の水分含量：約40〜45%**（選択肢 c の記述は正しい）
- 水浸け（浸水）と水切り（空気休止）を繰り返しながら水分を均一に吸収させる
- 所要時間：約40〜50時間

#### 大麦の構造と糊粉層（アリューロン層）

大麦粒は以下の主要部分から構成される。

```
[果皮・種皮（穀皮）] → 外層
[糊粉層（アリューロン層）] → 胚乳の最外層
[デンプン胚乳（内乳）] → 主にデンプンを含む
[胚（はい）] → 発芽の起点
```

**糊粉層（アリューロン層）**：
- **胚乳の一部**（最外層）であり、選択肢 d の記述は正しい
- 発芽時に胚から分泌されるジベレリン（植物ホルモン）を受け取り、**アミラーゼ・プロテアーゼなどの酵素を合成・分泌**する
- この酵素群がデンプン胚乳のデンプンやタンパク質を分解し、発酵に使える糖やアミノ酸を生成する（糖化の準備）

### 各選択肢の補足

- **a) プラネットはヨーロッパ以外にオーストラリアでも代表的な品種である**: 正しい記述。プラネットはヨーロッパとオーストラリア両方で広く栽培される主要醸造用品種。
- **b) 一般的に二条大麦は六条大麦に比べ、穀粒が小粒で穀皮が厚い傾向がある**: ✓ **誤り（正解）**。実際は逆で、二条大麦は穀粒が**大きく**、穀皮が**薄い**。
- **c) 製麦工程での浸麦終了時点の大麦の水分含量は40〜45％である**: 正しい記述。浸麦終了時の水分目標値は40〜45%で、これにより均一な発芽が促される。
- **d) 糊粉層は胚乳の一部であり、酵素の合成・分泌や発芽に必要なホルモンの伝達に関与する**: 正しい記述。糊粉層は胚乳最外層として、ジベレリンによるシグナルを受けて酵素を産生・分泌する重要な組織。

### 覚え方・関連事項

- **二条＝大きい・薄い・ビール向き**：「二条大麦はビール醸造の主役」と覚え、そこから「大粒・薄皮」を連想する
- **六条＝小さい・厚い・酵素力高い**：六条はタンパク質・酵素が豊富だが穀皮が厚くビールの品質に影響しやすい
- **浸麦終了＝40〜45%**：「浸麦で四十（40）五（5）分の水分」とリズムで覚える（ちなみに開始時は約12〜15%）
- **糊粉層の役割**：「ホルモン受容→酵素分泌」という2段階の連鎖を押さえる。ジベレリン→糊粉層→アミラーゼ産生の流れ
- 「誤っているものを選べ」型は、**正しそうに見えるが逆になっている記述**が狙われやすい。数値・方向性（大小・高低・厚薄）に特に注意する
