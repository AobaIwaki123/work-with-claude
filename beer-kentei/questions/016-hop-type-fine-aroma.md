# ホップの品種分類：ファインアロマ・ビター・アロマの違い

## 問題

ホップには様々なタイプがある。次の選択肢より「ファインアロマホップ」に該当するものを選べ。

**選択肢**

- a) カスケード
- b) テトナング
- c) マグナム
- d) ヘラクレス

## 正解

**b) テトナング**

## 解説

### なぜ正解か

テトナング（Tettnang）はドイツ南西部・バーデン＝ヴュルテンベルク州原産のホップで、**ファインアロマホップ（Fine Aroma Hop）** に分類される。α酸含量が低く苦味は穏やかだが、上品でスパイシー・フローラルな香りを持つ。同じファインアロマホップにはチェコ産の**ザーツ（Saaz）**がある。

### 背景知識

#### ホップの機能別分類

ホップは主にα酸含量（苦味の強さ）と香りの特性によって分類される：

| 分類 | 特徴 | α酸含量 | 代表品種 |
|------|------|---------|---------|
| **ファインアロマホップ** | 上品で繊細な香り、苦味は控えめ | 低（3〜5%程度） | テトナング、ザーツ、ハラタウアー、シュパルター |
| **アロマホップ** | 豊かな香り、苦味もある程度あり | 中（5〜8%程度） | カスケード、センテニアル、アマリロ |
| **ビターホップ** | 苦味付けに特化、香りは控えめ | 高（10〜20%以上） | マグナム、ヘラクレス、チヌーク |
| **デュアルパーパスホップ** | 苦味・香り両用 | 中〜高 | シムコー、コロンバス |

#### ファインアロマホップとノーブルホップの関係

ファインアロマホップの中でも特に品質が高いとされる伝統的なヨーロッパ産4品種を**ノーブルホップ（貴族ホップ）**と呼ぶ：

1. **テトナング**（ドイツ・バーデン） — スパイシー・ハーブ香
2. **ザーツ**（チェコ・ボヘミア） — 上品なフローラル・スパイシー香
3. **ハラタウアー**（ドイツ・バイエルン） — 穏やかなハーブ・フラワー香
4. **シュパルター**（ドイツ・シュパルト） — 繊細なスパイス・ハーブ香

ノーブルホップは伝統的なヨーロッパスタイルのラガー（特にピルスナー）に多用される。

#### 各品種の詳細

**テトナング（Tettnang）**
- 産地：ドイツ南西部、ボーデン湖畔
- α酸：3〜5%
- 香り：スパイシー、ハーブ、わずかにフローラル
- 用途：ドイツ系ラガー、ヴァイツェン、ピルスナー

**ザーツ（Saaz / Žatec）**
- 産地：チェコ北西部・ボヘミア地方
- α酸：3〜4%
- 香り：上品なスパイシー・フローラル
- 用途：ボヘミアンピルスナー（ピルスナーウルケル等）に不可欠

**カスケード（Cascade）**
- 産地：アメリカ・ワシントン州ほか
- α酸：4〜7%（中程度）
- 香り：シトラス（グレープフルーツ）・フローラル
- 用途：アメリカンエール・IPA。アメリカクラフトビール革命を象徴する品種

**マグナム（Magnum）**
- 産地：ドイツ（ハラタウ地方等）
- α酸：11〜16%（高い）
- 用途：煮沸初期の苦味付け用ビターホップとして広く使われる

**ヘラクレス（Herkules）**
- 産地：ドイツ
- α酸：12〜17%（非常に高い）
- 用途：高α酸のビターホップ。効率的な苦味付けに使用

### 各選択肢の補足

- **a) カスケード**: 誤り。カスケードは**アロマホップ**に分類される。ファインアロマホップではなくアメリカンクラフトビールで多用されるシトラス系の香りが特徴。
- **b) テトナング**: ✓ 正解。ドイツ産のファインアロマホップ。ノーブルホップの一つ。
- **c) マグナム**: 誤り。マグナムは高α酸の**ビターホップ**。苦味付けに特化しており、香りよりも効率的な苦味付与を目的に使われる。
- **d) ヘラクレス**: 誤り。ヘラクレスも**ビターホップ**。α酸含量が非常に高く、少量で強い苦味を付与できるため経済的なビターホップとして使われる。

### 覚え方・関連事項

- **ファインアロマ＝ノーブルホップ4品種（テトナング・ザーツ・ハラタウアー・シュパルター）** をまず覚える
- **カスケード（アロマ）≠ファインアロマ**: カスケードは「アロマ」だが「ファインアロマ」ではない。この区別が本問のポイント
- **マグナム・ヘラクレス＝ビターホップ**（高α酸、ドイツ産）
- 分類の判断軸：「α酸が低い→香り重視→ファインアロマ」「α酸が高い→苦味重視→ビター」
- ザーツ＝チェコ産ファインアロマ、テトナング＝ドイツ産ファインアロマ、とセットで産地と紐づけて覚える
