# 世界の言語でのビールの呼び名：中国語「啤酒」と各国語

## 問題

日本語では、ビールを「麦酒」などとも書くことがある。「ビール」を中国語で表記したものを次の選択肢より選べ。（2012年）

**選択肢**

- a) 美酒
- b) 啤酒
- c) 比酒
- d) 飛酒

## 正解

**b) 啤酒**

## 解説

### なぜ正解か

中国語でビールは**「啤酒（ピーチュウ / pí jiǔ）」**と表記する。「啤（ピー）」は「beer（ビール）」の音を漢字で当てた音訳文字であり、「酒（チュウ）」は中国語で酒類全般を指す語。日本語の「麦酒（ばくしゅ）」が原料（麦）を意味する字を使うのに対し、中国語の「啤」は音を写した当て字という違いがある。

### 背景知識

#### 世界各国語でのビールの呼び名

| 言語 | ビールの名称 | 発音 | 語源・備考 |
|------|------------|------|----------|
| **中国語** | 啤酒 | ピーチュウ（pí jiǔ） | 「啤」は「beer」の音訳 |
| **日本語** | ビール / 麦酒 | ビール / ばくしゅ | 「ビール」はオランダ語「bier」から。「麦酒」は原料の麦に由来 |
| **英語** | beer | ビア | ゲルマン語起源（古英語 beor） |
| **ドイツ語** | Bier | ビア | 英語と同語源 |
| **スペイン語** | cerveza | セルヴェーサ | ラテン語 cervisia（穀物由来の酒）から |
| **ロシア語** | pivo | ピーヴォ | スラブ語系。「飲み物」に由来 |
| **フランス語** | bière | ビエール | ドイツ語・英語と同語源 |
| **イタリア語** | birra | ビッラ | 同上 |

#### 「beer」系と「cerveza」系の語源分岐

世界のビールの呼び名は大きく2系統に分かれる：

- **「beer/bier」系（ゲルマン語系）**: 英語・ドイツ語・オランダ語・フランス語・イタリア語・日本語（カタカナ）など。古ゲルマン語の「beor」（発酵飲料）に由来するとされる
- **「cerveza/cervoise」系（ラテン語系）**: スペイン語・フランス語（古語 cervoise）など。ローマ帝国圏でビールを指したラテン語「cervisia」に由来

中国語・ロシア語などはこれらと異なる独自の系統を持つ。

#### 日本語「麦酒」と「ビール」の使い分け

- 「ビール」：外来語（カタカナ）表記。日常的に最も広く使われる
- 「麦酒（ばくしゅ）」：漢語的な表記。酒税法などの法律・公的文書では「麦酒」が使われることがある
- 明治期の文献では「ビール」の他に「ビイル」「ヒイル」などの表記も見られる

#### 「啤」という漢字について

「啤（ピー）」は中国語でビールを表すために作られた比較的新しい漢字（近代以降）。「口」へんに「卑」を組み合わせた形声文字で、「beer」の音（ビー）を写したものとされる。同様の音訳漢字として「可口可楽（コカコーラ）」「咖啡（コーヒー）」なども有名。

### 各選択肢の補足

- **a) 美酒（měi jiǔ）**: 誤り。「美酒」は中国語で「うまい酒・良い酒」を意味する熟語。ビールに限らず優れた酒全般を指す表現であり、ビールの固有名称ではない。
- **b) 啤酒（pí jiǔ）**: ✓ 正解。ビールの中国語表記。「啤」は「beer」の音訳。
- **c) 比酒（bǐ jiǔ）**: 誤り。「比」は「くらべる」を意味する漢字。「比酒」という表現はビールの正式名称ではない。音は近いが誤った選択肢。
- **d) 飛酒（fēi jiǔ）**: 誤り。「飛」は「とぶ」の意味。ビールとは無関係の造語的な誤答選択肢。

### 覚え方・関連事項

- **「啤酒＝ピーチュウ」**: 「啤」は「beer」の音を漢字にした字と覚える
- 試験頻出の多言語セット：**中国語「啤酒（ピーチュウ）」・スペイン語「cerveza（セルヴェーサ）」・ロシア語「pivo（ピーヴォ）」** の3つは一緒に覚える
- 「美酒」は「美しい・良い酒」の意味で紛らわしい選択肢。ビールの固有表記ではない
- 日本語「麦酒」の「麦」は原料、中国語「啤酒」の「啤」は音訳という違いを意識すると区別しやすい
