# ホップの名産地：チェコのザーツとファインアロマホップ

## 問題

ホップは独特の香りと苦味をビールに与える大事な原料である。世界的なホップの名産地とされているチェコの地方を次の選択肢より選べ。

**選択肢**

- a) ザーツ
- b) ハラタウ
- c) モーゼル
- d) ピルゼン

## 正解

**a) ザーツ**

## 解説

### なぜ正解か

チェコ（ボヘミア地方）の**ザーツ（Žatec）**は、世界最高峰の**ファインアロマホップ**の産地として世界的に知られている。ザーツ産ホップは「ザーツホップ（Saaz Hops）」と呼ばれ、繊細な花香・スパイシーな香り・マイルドな苦みを持ち、特にボヘミアンピルスナー（例：ピルスナー・ウルケル）の特徴的な香味を形成する不可欠な原料となっている。

### 背景知識

#### ホップの役割

ホップ（Humulus lupulus）はアサ科のつる性植物で、雌花（毬花）を醸造に使用する。主な役割：

1. **苦み付与**：α酸（フムロン等）が煮沸によりイソフムロンに変換され苦みを与える
2. **香り付与**：精油成分（ミルセン・リナロール・ゲラニオール等）が複雑な香りを生む
3. **防腐作用**：ホップの抗菌成分がビールの保存性を高める
4. **泡立ち向上・泡持ちの安定**：イソフムロンが泡の安定に寄与

#### ホップの種類分類

| 種類 | 特徴 | 代表品種・産地 |
|---|---|---|
| **ファインアロマホップ** | α酸含量低め・精油豊富・繊細な香り | ザーツ（チェコ）、ハラタウ伝統品種（ドイツ） |
| **アロマホップ** | 香り重視・苦み控えめ | ハラタウ（ドイツ）、フグル（イギリス） |
| **ビターホップ（高α酸）** | α酸含量高め・苦み付与主体 | チヌーク・マグナム |
| **デュアルパーパス** | 香り・苦みの両立 | シムコー・センテニアル（アメリカ） |

#### 世界の主要ホップ産地

| 産地 | 国 | 特徴 |
|---|---|---|
| **ザーツ（Žatec / Saaz）** | **チェコ** | **ファインアロマの聖地。繊細な花香・スパイシー** |
| **ハラタウ（Hallertau）** | **ドイツ** | 世界最大のホップ産地。多様なアロマ品種 |
| ヘレフォード・ウースター | イギリス | フグル・ゴールディングス等の伝統品種 |
| ヤキマ・バレー | アメリカ（ワシントン州） | アメリカン・ホップの一大産地。シトラス系品種が豊富 |
| ウィラメット・バレー | アメリカ（オレゴン州） | カスケード等のアメリカンアロマホップ |
| ネルソン・ソーヴィン | ニュージーランド | ソーヴィニヨン・ブランに似た白ワイン系香り |

#### ザーツホップの特徴

- **チェコ語表記**：Žatec（ジャテツ）
- **ドイツ語・英語表記**：Saaz（ザーツ）
- **α酸含量**：低め（約2〜5%）
- **香り成分**：花のような香り、スパイシー、ハーブ的なニュアンス
- **主な使用スタイル**：ボヘミアンピルスナー、チェコラガー、一部のジャーマンラガー
- **地理的表示**：「Žatec」はEUで地理的表示（Protected Geographical Indication）として保護されている

#### ハラタウ（Hallertau）について

ドイツ・バイエルン州にあるヨーロッパ最大・世界屈指のホップ産地。多様なアロマホップ品種（ハラタウ・ミッテルフリューh・スパルト・テトナング等）を産出し、ドイツビール全般に使われる。ザーツと並ぶヨーロッパ2大アロマホップ産地として試験頻出。

#### ピルゼン（Pilsen）との関係

同じチェコにある都市だが役割が異なる：
- **ザーツ**：ホップの産地
- **ピルゼン（Plzeň）**：世界初の淡色ラガー「ピルスナー」誕生の地（1842年、ピルスナー・ウルケル創業）。超軟水の水質がボヘミアンピルスナーの淡色・まろやかな風味を生んだ（問012参照）

### 各選択肢の補足

- **a) ザーツ**: ✓ 正解。チェコ・ボヘミア地方のファインアロマホップ産地。「Saaz」の名でも知られる。
- **b) ハラタウ**: 誤り。**ドイツ**・バイエルン州のアロマホップ産地。チェコではなくドイツの産地。世界最大のホップ産地として有名。
- **c) モーゼル**: 誤り。ドイツの**ワイン**銘醸地（モーゼル川流域）。ビール・ホップとは無関係。リースリングで知られる白ワインの産地。
- **d) ピルゼン**: 誤り。チェコの都市だが、ホップ産地ではなく**ピルスナービール誕生の地**（ビールの産地）。ホップの産地はザーツ。同じチェコという引っかけに注意。

### 覚え方・関連事項

- **「ザーツ＝チェコ＝ホップ」「ハラタウ＝ドイツ＝ホップ」「ピルゼン＝チェコ＝ビール（ピルスナー）」**：3つをセットで整理する
- **ピルゼンとザーツの混同注意**：どちらもチェコだが、ザーツはホップ、ピルゼンはビール（水と酵母の街）
- **モーゼルはワイン**：「モーゼル＝ドイツワイン」は別ジャンルの知識。ビール産地と混同しないよう注意
- **ファインアロマ＝ザーツの代名詞**：「ファインアロマホップの産地は？」という問いにもザーツと答えられるようにする
- ザーツホップを使ったピルスナー・ウルケルは「世界初の淡色ラガー」として問009（メルツェン・オクトーバーフェスト）と並ぶ重要な歴史的ビール。ザーツ（ホップ）＋ピルゼン（水・ビール）の組み合わせでボヘミアンピルスナーが誕生したという流れで覚えると関連知識が有機的につながる
