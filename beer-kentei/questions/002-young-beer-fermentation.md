# 若ビール：主発酵後・熟成前のビール

## 問題

主発酵工程が終了し、貯酒タンクで熟成させる前のビールを何というか。次の選択肢より選べ。

**選択肢**

- a) 若ビール
- b) 青ビール
- c) 無ろ過ビール
- d) 素ビール

## 正解

**a) 若ビール**

## 解説

### なぜ正解か

主発酵（一次発酵）が終了したばかりのビールは、まだ味が粗く、硫黄臭や未熟な香り成分（ジアセチルなど）が残っている。熟成によって丸みのある味わいに仕上がる前の「未完成な状態」を指して**若ビール（わかビール）**と呼ぶ。「若い＝未熟・成長途中」という日本語の語感をそのまま当てた用語で、英語では "green beer" とも呼ばれる。

### 背景知識

#### ビールの製造工程の流れ

```
仕込み（糖化・ろ過）→ 煮沸・ホップ添加 → 冷却 → 主発酵 → [若ビール] → 貯酒（熟成） → ろ過 → 製品
```

#### 主発酵（一次発酵）

- 酵母が麦汁中の糖をアルコールと CO₂ に分解する工程
- ラガービールでは約 8〜15°C で 7〜10 日間程度かけて行われる
- 発酵が終わると酵母は沈降し、ビールの液面が落ち着く

#### 貯酒・熟成（ラガリング）

- 若ビールを **貯酒タンク（ラガータンク）** に移して低温（0°C前後）で熟成させる工程
- 熟成の目的：
  1. **ジアセチルの除去**：酵母が二酢酸様の不快な風味物質を再吸収する
  2. **硫黄化合物の揮散**：硫化水素などが自然に抜けていく
  3. **タンパク質・酵母の沈降**：ビールの清澄化
  4. **炭酸ガスの溶解**：炭酸が馴染み、口当たりが滑らかになる
  5. **香味成分の調和**：各成分がバランスよく整う

#### 熟成期間

- 大量生産のラガーでは数週間〜1か月程度
- クラフトビールや伝統的なラガーでは数か月以上かける場合もある
- 「ラガー」の語源はドイツ語の **lagern（貯蔵する）** に由来する

### 各選択肢の補足

- **a) 若ビール**: ✓ 正解。主発酵終了後・熟成前の未熟なビールの正式名称。
- **b) 青ビール**: 誤り。英語の "green beer"（若ビールの英語訳）を直訳したような語感だが、日本語の正式用語は「若ビール」。「青ビール」という工程上の専門用語は存在しない。
- **c) 無ろ過ビール**: 誤り。ろ過工程を経ていないビール（酵母や澱が残った状態）の総称。製造工程の位置が異なり、熟成後に該当する場合もある。クラフトビールや「白ビール（ヴァイツェン）」が代表例。
- **d) 素ビール**: 誤り。ビール業界の工程用語としては使われない造語。「素」は「加工前・添加前」のニュアンスを持つが、この文脈では不正確。

### 覚え方・関連事項

- **「若い＝未熟」** のイメージで覚える。人間でも「若い」は「まだ成長途中」を意味するのと同じ。
- 英語の **"green beer"** は「若ビール」の直訳で、試験では英語との対応も意識すると理解が深まる。
- **主発酵 → 若ビール → 貯酒（熟成） → ろ過 → 製品** という工程の流れをセットで覚えておくと、関連問題にも対応しやすい。
- ジアセチルは「バタースコッチ」のような風味を持つ欠陥臭として知られており、熟成で取り除かれることも関連知識として押さえておくと良い。
