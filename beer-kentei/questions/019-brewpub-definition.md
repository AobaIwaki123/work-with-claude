# 醸造設備を併設するパブの名称──ブルーパブ

## 問題

ビールの醸造設備を併設しているパブを一般的に何と呼ぶか、最も適切なものを次の選択肢より選べ。（2017年）

**選択肢**

- a) ビアホール
- b) ビアレストラン
- c) ブルーパブ
- d) ブルワー

## 正解

**c) ブルーパブ**

## 解説

### なぜ正解か

**ブルーパブ（Brewpub）**は**Brewery（醸造所）＋Pub（パブ）**を組み合わせた造語で、**店内に醸造設備を持ち、自家醸造したビールをその場で提供する飲食店**のことを指す。日本では酒税法上の制約があり、ビールの年間最低製造数量（60kl）を満たせない小規模店舗では、最低製造数量が**6kl**と少ない**発泡酒製造免許**を取得してブルーパブを開業しているケースが多い。

### 背景知識

#### ブルーパブの特徴

| 項目 | 内容 |
|------|------|
| 定義 | 醸造設備を店内に持つ飲食店 |
| 提供するもの | 自家醸造ビール（または発泡酒）を同一施設内で販売・提供 |
| 英語表記 | Brewpub（ブリュワリー＋パブ） |
| 日本の法的位置づけ | 発泡酒製造免許（最低6kl）での開業が多い |

#### 日本のクラフトビール・ブルーパブと酒税法

1994（平成6）年の酒税法改正でビールの年間最低製造数量が**2,000kl→60kl**に引き下げられ、地ビール・クラフトビールのブームが始まった。さらに発泡酒（麦芽使用比率50%未満等）の最低製造数量は**6kl**と低く設定されているため、小規模なブルーパブは発泡酒免許で運営するケースが現実的な選択となっている。

#### ビール関連施設の用語整理

| 名称 | 定義 |
|------|------|
| **ブルーパブ（Brewpub）** | 醸造設備を併設したパブ・飲食店 |
| ビアホール | 大きなホールでビールを提供する飲食施設（醸造設備なし） |
| ビアレストラン | レストランスタイルのビール提供施設（醸造設備なし） |
| ブルワリー（Brewery） | 醸造所。飲食スペースを持たない場合もある |
| ブルワー（Brewer） | ビールの**つくり手**（人・醸造家） |
| タップルーム | 醸造所に併設されたビール提供スペース（ブルーパブに近い） |

#### ブルーパブとブルワリータップルームの違い

- **ブルーパブ**：飲食店が主体で、醸造設備を店内に持つ
- **タップルーム**：醸造所（ブルワリー）が主体で、飲食スペースを併設

実態としては重なることが多く、明確な区別は文脈による。

### 各選択肢の補足

- **a) ビアホール**: 誤り。広いホール空間でビールを提供する施設。自社での醸造設備は持たないのが一般的。日本初は1899年の恵比寿ビールBeer Hall（問題009参照）。
- **b) ビアレストラン**: 誤り。レストランスタイルでビールを提供する施設を指す一般的な呼称。醸造設備の有無は問わないが、ブルーパブの正式な呼称ではない。
- **c) ブルーパブ**: ✓ 正解。Brewery＋Pubの合成語。醸造設備を店内に持つ飲食店。
- **d) ブルワー**: 誤り。ブルワー（Brewer）はビールの**つくり手（醸造家）**を指す人名詞。施設の名称ではない。

### 覚え方・関連事項

- **「ブルー（Brew）パブ＝醸造（Brew）するパブ」**：語の成り立ちをそのまま覚える
- ブルワー（人）とブルーパブ（場所）を混同しない：同じ「ブルー」でも指すものが異なる
- 日本の法的ポイント：ビール免許は最低**60kl**、発泡酒免許は最低**6kl**
  - 10分の1の数量でよいため、小規模ブルーパブは発泡酒免許で開業するケースが多い
- 問題009（ビヤホールの日）と連動：ビアホールとブルーパブは別概念
- 2017年出題実績あり
