# 大麦から麦芽をつくる工程──製麦

## 問題

大麦から麦芽をつくる工程を何というか、次の選択肢より適切なものを選べ。（2012年）

**選択肢**

- a) 仕込
- b) 製麹
- c) 製麦
- d) 製芽

## 正解

**c) 製麦**

## 解説

### なぜ正解か

**製麦（せいばく）**とは大麦を麦芽（モルト）に加工する工程の総称で、英語では**モルティング（Malting）**に相当する。大麦を水に浸して発芽させ、その後乾燥・焙燥することで、デンプンやタンパク質を分解する酵素（アミラーゼ・プロテアーゼなど）が活性化し、酵素で分解されやすい状態に変化した**麦芽（モルト）**が完成する。

### 背景知識

#### 製麦の三段階工程

```
大麦
 ↓ ①浸麦（しんばく）Steeping
   水に浸して水分を吸わせる（水分を約12%→45%に）
 ↓ ②発芽（はつが）Germination
   約15〜20℃の環境で4〜6日発芽させる
   → 酵素（アミラーゼ・プロテアーゼ等）が生成・活性化
   → 胚乳のデンプンが分解されやすい状態に変化
   この段階の産物を「グリーンモルト（緑麦芽）」と呼ぶ
 ↓ ③焙燥（ばいそう）Kilning
   50〜80℃以上の熱風で乾燥させ発芽を止める
   → 水分を約3〜5%に低下
   → 焙燥温度・時間で麦芽の色・香りが決まる
麦芽（モルト）完成
```

#### 焙燥温度と麦芽の種類

| 焙燥温度 | 麦芽の種類 | 色 | 主な用途 |
|---------|----------|-----|---------|
| 80℃以下（低温） | ペールモルト | 淡色 | ピルスナー・ペールエール |
| 100〜150℃ | クリスタルモルト・カラメルモルト | 琥珀色 | エール・アンバー系 |
| 200〜220℃ | チョコレートモルト・ブラックモルト | 黒褐色 | スタウト・ポーター |

#### 製麦の目的まとめ

1. **酵素の生成と活性化**：アミラーゼ・プロテアーゼ等がデンプン・タンパクを分解できる状態に
2. **成分の変化**：大麦の固い細胞壁が柔らかくなり酵素が作用しやすくなる（溶解）
3. **香りと色の付与**：焙燥工程でメイラード反応によりモルトフレーバーと色が生成

#### 製麦と他の酒類製造工程との比較

| 工程名 | 読み | 目的 | 使用する酒類 |
|--------|------|------|------------|
| **製麦（せいばく）** | | 大麦→麦芽 | **ビール・ウイスキー** |
| 製麹（せいきく） | | 米→麹 | 日本酒・本格焼酎・味噌 |
| 仕込（しこみ） | | 原料の混合・糖化・発酵準備 | 各種醸造酒全般 |

### 各選択肢の補足

- **a) 仕込**: 誤り。仕込は麦芽が完成した後の工程で、麦芽を温水に混合してマイシェをつくりビールを醸造する工程を指す。製麦（大麦→麦芽）より後の段階。
- **b) 製麹（せいきく）**: 誤り。麹（こうじ）菌を米などに繁殖させる工程で、日本酒・本格焼酎・味噌・醤油などで用いられる。ビール製造とは無関係。「麹」と「麦芽」を混同させる引っかけ。
- **c) 製麦**: ✓ 正解。大麦を浸麦→発芽→焙燥の三段階で麦芽に加工する工程。英語名はモルティング。
- **d) 製芽**: 誤り。「製芽」という正式な醸造用語は存在しない。「発芽させる」という意味に聞こえるが、製麦工程の正式名称ではない造語。

### 覚え方・関連事項

- **「大麦→麦芽＝製麦（モルティング）」**：「麦を製す」という漢字の意味そのまま
- 製麦の三段階：**浸麦→発芽→焙燥**（「浸・発・焙」で覚える）
- 製麹（せいきく）との区別：麦芽はビール、麹は日本酒・焼酎
- 問題014・015・016との連動：製麦で生成された麦芽が仕込工程（マイシェ・糖化・タンパク休止）に使われる
- 焙燥温度でビールの色が決まる点は、ビアスタイル（淡色〜黒色）との関連でも頻出
- 2012年出題実績あり
