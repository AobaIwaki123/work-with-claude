# ビヤホールの日は何月何日か──日本初のビヤホール開業

## 問題

1899（明治32）年、現在の銀座8丁目に日本初のビヤホールがオープンしたことにちなんで、日本記念日協会に登録されている「ビヤホールの日」を次の選択肢より選べ。（2014年）

**選択肢**

- a) 7月14日
- b) 7月24日
- c) 8月4日
- d) 8月14日

## 正解

**c) 8月4日**

## 解説

### なぜ正解か

1899（明治32）年**8月4日**、日本麦酒醸造会社の**馬越恭平（まごし きょうへい）**が現在の銀座8丁目に「**恵比寿ビール Beer Hall**」を開業した。これが日本初のビヤホールである。この開業日にちなみ、**8月4日**が「ビヤホールの日」として日本記念日協会に登録されている。

### 背景知識

#### 馬越恭平と日本麦酒醸造会社

馬越恭平（1844〜1933）は明治時代の実業家。日本麦酒醸造会社（恵比寿ビールの製造元）の経営に携わり、日本のビール産業の発展を牽引した人物として知られる。恵比寿ビールは1890年（明治23年）に東京・目黒で製造開始され、品質の高さで評判を得ていた。

#### 日本初のビヤホール「恵比寿ビール Beer Hall」

| 項目 | 内容 |
|------|------|
| 開業日 | 1899年（明治32年）8月4日 |
| 場所 | 現在の東京・銀座8丁目 |
| 運営 | 日本麦酒醸造会社（馬越恭平） |
| ブランド | 恵比寿ビール |
| 意義 | 日本初のビヤホール／西洋式ビール飲用文化の定着に貢献 |

#### ビヤホールという文化

ビヤホールはドイツのビアホール（Bierhaus）文化を源流とし、大きなホールでビールを注文し、多くの人と賑やかに飲む西洋の社交スタイルを取り入れた施設。明治時代の文明開化の象徴の一つとして、銀座という立地で多くの市民・文化人に親しまれた。現在も「銀座ライオン」（サッポロライオン運営）が同地区で営業を続けており、日本のビヤホール文化の系譜を継いでいる。

#### 日本記念日協会登録の「ビール関連記念日」

| 記念日 | 日付 | 内容 |
|--------|------|------|
| ビヤホールの日 | 8月4日 | 1899年・日本初ビヤホール開業日 |
| ビールの日 | 6月29日 | ビール酒造組合が制定 |

### 各選択肢の補足

- **a) 7月14日**: 誤り。ビール・ビヤホールに関連する記念日ではない。7月14日はフランス革命記念日（バスティーユの日）。
- **b) 7月24日**: 誤り。日付として実在しないビール記念日。選択肢の中で紛らわしいが根拠なし。
- **c) 8月4日**: ✓ 正解。1899年（明治32年）8月4日、恵比寿ビール Beer Hall が銀座8丁目に開業。日本記念日協会登録「ビヤホールの日」。
- **d) 8月14日**: 誤り。正解の8月4日と混同しやすい誤答。「8月」は正しいが「14日」は誤り。

### 覚え方・関連事項

- **「8（ビール）の4日」**：8月4日 → 「ハチ（蜂）のビール」「8＝ビアホール」と語呂で覚える
- 正解の数字を確実に：**8月4日・銀座8丁目・1899（明治32）年**と「8」が続くのが特徴
