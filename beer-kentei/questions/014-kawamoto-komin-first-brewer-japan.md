# 日本で最初にビールを醸造した人物：川本幸民

## 問題

「化学新書」の中でビール醸造を紹介し、上面発酵と下面発酵の違いなどを詳しく解説した、日本人で最初にビールを醸造したといわれている人物を次の選択肢より選べ。

**選択肢**

- a) 徳川 吉宗
- b) 坂本 龍馬
- c) 川本 幸民
- d) 黒田 清隆

## 正解

**c) 川本 幸民**

## 解説

### なぜ正解か

**川本幸民（かわもと こうみん、1810〜1871）** は江戸時代後期の蘭学者・化学者で、オランダ語文献を訳した著作『化学新書』（1861年刊）の中でビールの醸造法を紹介し、上面発酵と下面発酵の違いを詳述した。マッチや銀板写真（ダゲレオタイプ）など西洋の最新技術を旺盛に試作した探求心から、ビールも自ら醸造したであろうと推測されており、「日本人で最初にビールを醸造した人物」として語られる。

### 背景知識

#### 川本幸民とはどんな人物か

川本幸民は摂津三田藩（現・兵庫県三田市）の藩医の家に生まれ、江戸で蘭方医学・蘭学を修めた。1840年代から50年代にかけて蘭書の翻訳・研究に没頭し、化学・物理・鉱山学などを幅広く紹介した。代表的な業績は以下の通り。

| 業績 | 内容 |
|------|------|
| **マッチの試作** | 日本で初めてマッチを自作したとされる |
| **銀板写真（ダゲレオタイプ）の試作** | 日本初の写真撮影に挑んだ人物の一人 |
| **『化学新書』（1861年）** | オランダ語化学書を訳した著作。ビール醸造の解説を含む |
| **ビール醸造** | 上記著作への理解と探求心から醸造を試みたと推測される |

#### 『化学新書』とビール醸造の記述

『化学新書』はオランダ人化学者が著した教科書の翻訳・解説書で、醸造・発酵・化学反応など当時の最新知識を収録している。この中で川本はビールの製造工程を解説し、**上面発酵（エール）と下面発酵（ラガー）の違い**にも言及した。幕末の日本にこれほど体系的なビール醸造の記述が存在したことは、蘭学の水準の高さを示している。

#### 日本のビール史における位置づけ

| 時期 | 出来事 |
|------|--------|
| 1853年頃 | 川本幸民がビールを醸造したと推測される時期 |
| 1869年 | ノルウェー人ウィリアム・コープランドが横浜に「スプリング・バレー・ブルワリー」を設立（日本初の商業醸造所） |
| 1870年 | 開拓使麦酒醸造所設立（札幌）→後のサッポロビール |
| 1872年 | 渋谷醸造所（→後のキリンビール）創業 |

川本の試醸は商業的な醸造所設立より十数年前の出来事であり、「個人が学術的好奇心から行った日本初の試み」として位置づけられる。

#### 幕末〜明治の蘭学者とビール

黒船来航（1853年）前後の日本では、西洋文化への関心が急速に高まっていた。川本のような蘭学者は単なる翻訳者にとどまらず、自ら実験・試作することで西洋の技術を体得しようとした。ビール醸造もその一環であり、「書いたなら作る」という実学の精神を体現している。

### 各選択肢の補足

- **a) 徳川 吉宗**: 江戸幕府8代将軍（1684〜1751）。享保の改革で知られる。川本幸民より約1世紀前の人物で、ビール醸造との関係はない。
- **b) 坂本 龍馬**: 幕末の志士（1836〜1867）。ビールを飲んだという逸話は残るが、醸造した記録はない。同時代の人物として混同しやすいので注意。
- **c) 川本 幸民**: ✓ 正解。蘭学者・化学者。『化学新書』でビール醸造を解説し、自ら試醸したとされる日本初のビール醸造者。
- **d) 黒田 清隆**: 明治の政治家・軍人（1840〜1900）。開拓使長官として北海道開拓に貢献し、1876年の開拓使麦酒醸造所（札幌）設立に深く関与した人物。ビール史への貢献はあるが、「最初に醸造した人物」ではない。

### 覚え方・関連事項

- **「川本幸民＝化学新書＝日本初醸造」** の三点セットで覚える。
- **「マッチも写真もビールも作った蘭学者」** というイメージで川本幸民の人物像を固める。
- **黒田清隆との混同に注意**: 黒田は「札幌（開拓使）のビール」の父的存在。川本は「日本初の個人醸造者」。役割が全く異なる。
- 問題文の「推測されています」という表現が重要。史料に醸造の直接記録が残っているわけではなく、著作の内容と彼の性格・行動パターンから推測されている点を押さえておく。
- 日本のビール史の人物問題は頻出。川本幸民・コープランド（スプリング・バレー）・渋沢栄一（ジャパン・ブルワリー）・黒田清隆（開拓使）の4名の役割を整理しておくと対応できる。
