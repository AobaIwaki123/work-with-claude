# 上面発酵ビールの特徴──誤っているものを選べ

## 問題

上面発酵ビールに関する説明として誤っているものを、次の選択肢より選べ。（2017年）

**選択肢**

- a) 下面発酵より発酵温度が低い
- b) 下面発酵より発酵期間が短い
- c) 下面発酵より歴史が古い
- d) 豊かな味わいと香りが特徴

## 正解

**a) 下面発酵より発酵温度が低い**

## 解説

### なぜ正解か

これは**「誤っているもの」を選ぶ問題**である。上面発酵（エール）の発酵温度は**15〜25℃**で、下面発酵（ラガー）の**10℃前後**より**高い**。したがって「下面発酵より発酵温度が低い」は**誤り**。

### 背景知識

#### 上面発酵と下面発酵の数値比較

| 項目 | 上面発酵（エール） | 下面発酵（ラガー） |
|------|-----------------|-----------------|
| **発酵温度** | **15〜25℃（高い）** | **10℃前後（低い）** |
| **発酵期間** | **3〜5日（短い）** | **1週間〜10日（長い）** |
| 酵母の位置 | 液面上部に浮く | タンク底部に沈む |
| 貯蔵熟成 | 比較的短期間 | 長期低温熟成（ラグリング） |
| 歴史 | **古い**（人類が最初に醸造） | 比較的新しい（19世紀以降） |
| 風味 | フルーティー・複雑・豊か | すっきり・クリア |

#### 選択肢の正誤まとめ

| 選択肢 | 内容 | 正誤 |
|--------|------|------|
| a | 下面発酵より発酵温度が低い | **誤り**（上面の方が高い）← 正解 |
| b | 下面発酵より発酵期間が短い | 正しい（3〜5日 < 1〜2週間） |
| c | 下面発酵より歴史が古い | 正しい（エールが先・ラガーは19世紀） |
| d | 豊かな味わいと香りが特徴 | 正しい（エールの特徴） |

#### 上面発酵の歴史的背景

上面発酵（エール）は人類が最初に醸造したビールの製法で、常温近くでも発酵できるため特別な冷蔵設備が不要だった。一方、下面発酵（ラガー）は冷涼な環境が必要であり、冷蔵技術の発展した**19世紀以降**に普及した比較的新しい製法である。現在では世界のビール消費量の大半をラガーが占めるが、歴史的な先行者はエールである。

#### 上面発酵酵母の特性

**Saccharomyces cerevisiae**（サッカロマイセス・セレビシエ）が上面発酵に使われる酵母で、高温活性・短期発酵・香気物質（エステル類）を多く産生することが特徴。これが「豊かな味わいと香り」（選択肢d）の科学的な背景である。

### 各選択肢の補足

- **a) 下面発酵より発酵温度が低い**: ✓ これが誤りの選択肢（正解）。上面発酵は15〜25℃で、下面発酵の10℃前後より**高い**。逆の説明である。
- **b) 下面発酵より発酵期間が短い**: 正しい記述。上面（3〜5日）は下面（1〜2週間）より短い。誤答に見えるが正しい。
- **c) 下面発酵より歴史が古い**: 正しい記述。常温で醸造できるエールが先、低温が必要なラガーは19世紀以降。
- **d) 豊かな味わいと香りが特徴**: 正しい記述。エール酵母が高温発酵でエステル類を多産するため、フルーティーで複雑な香りが生まれる。

### 覚え方・関連事項

- **「エール（上面）は高温・短期」「ラガー（下面）は低温・長期」**：対になる数値をセットで覚える
  - 上面：**15〜25℃、3〜5日**
  - 下面：**10℃前後、1〜2週間**
- 「誤りを選ぶ」問題形式に注意。選択肢を素直に読むと「温度が低い方がラガーっぽい」と正しいように感じてしまう引っかけ
- 歴史の古さ：**エール（上面）→ ラガー（下面）**の順序は問題011（ラガーの語源）とも連動
