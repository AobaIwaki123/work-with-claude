# 「東洋のビール王」と呼ばれた人物──馬越恭平

## 問題

「東洋のビール王」と呼ばれた人物の名前を次の選択肢より選べ。（2017年）

**選択肢**

- a) 岩崎 弥之助
- b) 鳥井 駒吉
- c) 中埜 又左衛門
- d) 馬越 恭平

## 正解

**d) 馬越 恭平**

## 解説

### なぜ正解か

**馬越恭平（まごし きょうへい、1844〜1933）**は、1891（明治24）年に経営不振の日本麦酒醸造会社の再建を託された実業家。徹底した経営合理化でわずか1年で黒字転換を実現し、その後1899（明治32）年8月4日に銀座8丁目に日本初のビヤホール「恵比寿ビール Beer Hall」を開業。さらに日本麦酒・大阪麦酒・札幌麦酒の三社合併により**大日本麦酒**を誕生させた中心人物として「**東洋のビール王**」と称された。

### 背景知識

#### 馬越恭平の主な功績年表

| 年 | 出来事 |
|----|--------|
| 1844年 | 出生 |
| 1891（明治24）年 | 日本麦酒醸造会社の再建を託されわずか1年で黒字化 |
| 1899（明治32）年8月4日 | 銀座8丁目に日本初のビヤホール「恵比寿ビール Beer Hall」を開業 |
| 1906（明治39）年 | 日本麦酒・大阪麦酒・札幌麦酒の三社合併により**大日本麦酒**を設立 |
| 1933年 | 逝去 |

#### 大日本麦酒とは

大日本麦酒（だいにほんびーる）は1906年に設立された日本最大のビール会社で、戦後の1949年に独占禁止法により**朝日麦酒（現・アサヒビール）**と**日本麦酒（現・サッポロビール）**に分割解体された。

#### 選択肢の人物と日本ビール史の関係

| 人物 | 本来の役割・所属 |
|------|----------------|
| **馬越恭平** | 日本麦酒醸造会社再建・大日本麦酒設立・東洋のビール王 |
| 岩崎弥之助 | 三菱財閥2代目総帥。ビール業界とは直接の関係は薄い |
| 鳥井駒吉 | サントリー創業者・鳥井信治郎の父。洋酒業界との関連はあるが別人 |
| 中埜又左衛門 | 愛知・半田の醸造家。カブトビール（丸三麦酒）の創業者として知られる |

#### ビヤホール開業との連動（問題009）

馬越恭平が1899年8月4日に開業した「恵比寿ビール Beer Hall」は問題009で扱った「ビヤホールの日（8月4日）」の由来である。馬越という人物と、ビヤホールの日・恵比寿ビール・大日本麦酒という事績をセットで覚えることが重要。

### 各選択肢の補足

- **a) 岩崎弥之助**: 誤り。三菱財閥の2代目。実業家として有名だが、ビール産業との直接的な関わりは知られていない。
- **b) 鳥井駒吉**: 誤り。サントリー創業者・鳥井信治郎の父の名前に似るが、ビール王の称号とは無関係。試験の引っかけとして名前が紛らわしい。
- **c) 中埜又左衛門**: 誤り。愛知県半田市の中埜家はカブトビール（丸三麦酒）の経営者として日本ビール史に名を残すが、「東洋のビール王」は馬越恭平の称号。
- **d) 馬越恭平**: ✓ 正解。日本麦酒醸造会社の再建・日本初ビヤホール開業・大日本麦酒設立の三大事績で「東洋のビール王」の称号を得た。

### 覚え方・関連事項

- **「馬越＝ビール王＝ビヤホール＝8月4日＝銀座8丁目」**：すべて8に縁のある馬越恭平
- 問題009（ビヤホールの日）の主役が馬越恭平：同一人物の別問題として連動
- 大日本麦酒→戦後分割：**アサヒ＋サッポロ**という現代大手の源流として覚えておく
- 中埜又左衛門（カブトビール）は名古屋・半田の地域史で出題されることがある別の人物
- 2017年出題実績あり
